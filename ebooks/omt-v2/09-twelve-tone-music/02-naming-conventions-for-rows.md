# 音列的命名惯例

> **要点**
>
> - 本章逐一介绍表示十二音材料的各种不同方式：
> 	- 用音名或音级来表示音高；
> 	- 用 P<sub>0</sub> 从 C 开始（固定零点）或 P<sub>0</sub> 从我们自选之处开始（可动零点）来表示音列与变换；
> 	- 把这些不同的音列惯例编排成矩阵。
> - 在阅读其他关于十二音音乐的著述时，要对这些惯例中的任何一种有心理准备。但在你自己的工作中，只需选择一种你觉得顺手的，并一致地使用它。

在分析十二音音乐时，标记音列、变换、乃至音高和音程，都有不同的惯例。本章比较你在分析文献中最可能遇到的主要做法。重点在于音列与矩阵，不过在谈到这些之前，我们先处理音高本身。

## 音高

正如我们在[本书前文](../08-20th-and-21st-century-techniques/02-pitch-and-pitch-class.md)所见，在某些分析语境中，使用音级记法（[整数](../08-20th-and-21st-century-techniques/02-pitch-and-pitch-class.md)，C 为 0，B 为 11）来替代把这些音拼写出来（例如 C♯ 与 D♭），是有用的。这一惯例主要与非调性音乐（包括大多数十二音音乐）联系在一起；在这类音乐中，它便于执行我们所见过的那类数学运算（在[音级集合分析](../08-20th-and-21st-century-techniques/04-pc-sets-normal-order-and-transformations.md)与[十二音音乐](01-basics-of-twelve-tone-theory.md#operations)中都是如此），也便于回避音高拼写的问题。十二音作品中使用的音高拼写往往仍有其逻辑，但这种逻辑往往是另一种、也许不那么可推广的逻辑。例如，在音列形式的表示中使用特定的音高拼写，通常并不像调性音乐中音阶的各音那样，反映某种层级或调性。

## 音列

对于音列而言，记谱与标记方式的主要差别，集中在这样一个选择上：我们让音列以哪个音为中心来组织：

1. 在所有语境中都使用**同一个音**（按惯例，这个音是 C）
2. 使用**对当下音乐语境而言重要**的某个音

例如，在[十二音理论基础](01-basics-of-twelve-tone-theory.md)一章中，我们把伊丽莎白·勒琴斯的《经文歌》音列排成从 C 开始，得到十二音音列 0–11–3–7–8–4–2–6–5–1–9–10。另一种做法是，我们可以让 P<sub>0</sub> 从 D 开始，因为最先进入的声部（女低音）从 D<sub>4</sub> 开始，并在这个音高水平上唱出这个原形音列的第一个六音组。[^1] 这样得到的 P<sub>0</sub> 就是 2–1–5–9–10–6–4–8–7–3–11–0。

### 方案一：P<sub>0</sub> 从 C 开始（固定零点）

在这种惯例中，无论你认定原形是什么，该形式从 C 开始的移位就是 P<sub>0</sub>。这大概是今天最常见的惯例，有时称为“零点中心”或“固定零点”（类比调性音乐中的唱名体系）。

由于我们把 P<sub>0</sub> 设为从 C 开始，I<sub>0</sub> 也从 C 开始，而 R<sub>0</sub> 和 RI<sub>0</sub> 则*结束*于 C。把 P<sub>0</sub>、I<sub>0</sub> 与 R<sub>0</sub>、RI<sub>0</sub> 这样分开是有道理的，因为我们希望 P<sub>0</sub> 与 R<sub>0</sub> 互为严格逆行（I<sub>0</sub> 与 RI<sub>0</sub> 亦然）。理论上，我们也可以采用一种更为彻底“零点中心”的体系，让 P<sub>0</sub>、I<sub>0</sub>、R<sub>0</sub> 和 RI<sub>0</sub> 全都从 C 开始，但人们并没有广泛采用这种惯例。

总结如下：

- P<sub>0</sub> 以 C 开始
- I<sub>0</sub> 以 C 开始（与 P<sub>0</sub> 同一音级）
- R<sub>0</sub> 以 P<sub>0</sub> 的最后一个音开始（按定义，不是 C）
- RI<sub>0</sub> 以 I<sub>0</sub> 的最后一个音开始（按定义，不是 C）

### 方案二：P<sub>0</sub> 从我们自选之处开始（可动零点）

在另一种方法中，P<sub>0</sub> 被指派给音列的第一个形式或最有意义的那个形式——无论该音列是从哪个音级开始的。视语境而定，这一点可能从作品中显而易见，可能从分析中推导出来，也可能是半任意地指定的。移位和其他运算随后都以同样的方式、相对于那个 P<sub>0</sub> 形式推算出来。这种惯例有时称为“原初中心”或“可动零点”（继续沿用唱名的类比）。

总结如下：

- P<sub>0</sub> 采用由分析者选定的移位（因而是以某个音开始）
- I<sub>0</sub> 仍与 P<sub>0</sub> 从同一个音开始
- R<sub>0</sub> 仍以 P<sub>0</sub> 的最后一个音开始
- RI<sub>0</sub> 仍以 I<sub>0</sub> 的最后一个音开始

### 相同？不同？更好？更差？

正如这两份总结所显示的，这些命名惯例其实并没有那么不同。值得重复的是：对所有命名体系来说，移位及其他运算都以同样的方式运作，所以问题大体上只在于你从哪里开始：你用哪个音列形式作为参照形式，让其他形式与之关联。

而且，正如多重平行命名惯例出现时常见的情形，每种做法都各有长处与短板。如果你分析的音乐让你想以富有音乐感的方式指派 P<sub>0</sub>，那么可动零点惯例也许正合你的需要。但你若走上这条路，大概就会觉得自己在每一次分析中都必须为 P<sub>0</sub> 的音高水平找一个“好”理由，而这并不总是恰当的。固定零点体系的好处是清晰与一致。这大概就是它在晚近学界变得更常见的原因，但这并不必然使它“更好”。

事实上，在许多情况下，甚至无法明确哪个取向应当是 P、哪个应当是 I（或者 R）。遗憾的是，目前还没有一个被广泛承认的体系来做这种判定。

- 我们围绕选定的音/移位（这里为 D）来组织音列类。
- 但我们仍按另一种方案（**P<sub>0</sub>** 从 C 开始）来标记音列形式。

### 总结 {#summary}

总之，最上面一行可以是：

- **P<sub>0</sub>**，从 0 开始
- **P<sub>0</sub>**，从 n 开始（这里 n 为 2）
- **P<sub>n</sub>**，从 n 开始

所有这些命名与矩阵生成惯例都确实存在。最好的办法就是留意这些选项，并且在你遇到某一种时，确认自己想到的是正确的惯例（尤其是在矩阵没有明确标出音列名称的时候）。
