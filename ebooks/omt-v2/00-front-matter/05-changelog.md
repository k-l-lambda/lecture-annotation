# 更新日志

以下是 *OMT* 的重大修改与改进列表。小幅修改（修正错别字、增添练习表、外观调整等）不一定列出。

我们不会在学年期间（九月至次年五月）对教材做重大改动。

## 2025 年夏

- 基础乐理
	- 练习表更新
		- 音程、三和弦与七和弦练习表更名（1–5 改为 A–E）
		- 新的音程练习表或更新后的练习表：
			- D 与 E 各有两个新活动：音程转位与分析
			- 四份新练习表，分别聚焦 ma/mi/P 与 d/A 音程（各两个版本）
		- 大小调音阶各章的练习表更名：
			- 音阶：大调 → 大调音阶
			- 调号：大调 → 大调调号
			- 等等。
		- 大小调音阶练习表上的三个新活动：
			- 按级数与名称识别大调/小调音阶级数
			- 在给定调号内写音阶
			- 针对不匹配的调号写音阶
		- 每份大小调音阶练习表的第二版
		- 谱表记谱中的半音与全音：新增仅有高音/低音谱号的版本；两个版本都增加了旋律分析；更新了说明；可编辑版本现在采用 .mscz 格式而非 .docx
		- 等音等价：新增仅有高音/低音谱号的版本；可编辑版本现在采用 .mscz 格式而非 .docx
		- 单拍子与复拍子练习表：“在单拍子/复拍子中重新划分符杠”改名为“在单拍子/复拍子中记写节奏”；单拍子增加了一个谱例；复拍子的排版方向改为横向，使整个谱例排在一行内。
		- 自然音调式练习表：1 和 2 更名为 A 和 B；增加了高音/低音谱号版本；所有版本都新增了一个活动，要求在同主音大调/小调的调号内写调式。
	- 每章都新增了“延伸阅读”一节；增加了大量互动谱例；修正了错别字、失效链接等，并做了小幅修改
	- 阅读谱号：新增关于八度高音谱号的内容（“阅读高音谱号”一节）并附谱例；新增“其他 C 谱号”一节（附谱例）；新增“中性谱号”一节（附谱例）
	- 记谱法的其他方面：速度与结构特征两节新增了带谱例的内容（a tempo、一小节/两小节反复记号，以及 d.c./d.s. al fine/coda）
	- 其他节奏基础：在章首增加了新谱例
	- 大调音阶：在章首增加了新谱例
	- 小调音阶：在章首增加了新谱例
	- 自然音调式：新增“五声音阶音集”一节并附谱例；在“半音音阶”一节新增谱例与文字
- 视唱练耳附录（导言）：补入了几乎所有文字
	- 转位一章大幅重写，并更换了 URL（[https://viva.pressbooks.pub/openmusictheory/chapter/inversion](../01-fundamentals/20-inversion.md)）
	- 通奏低音各章大幅重写
	- 七和弦之后若干基础乐理章节重新排序
- 自然音和声：新增一章关于自然音模进
