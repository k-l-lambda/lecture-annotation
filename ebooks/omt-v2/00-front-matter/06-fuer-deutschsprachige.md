# 致德语读者

[*查看英文版*](#english)

## 欢迎使用 Open Music Theory！

尽管本教材是用英语（美式英语）写成的，但它在世界各地都有人阅读和使用。我们虽然遗憾的是没有能力把教材逐学科精确地译成各种语言，但如果国际读者能从这些内容中受益，我们是非常高兴的。

当然，对于所有熟悉西方音乐记谱法的人来说，音乐谱例同样是可以读懂的；此外，世界各地的人们越来越熟悉英语，自动翻译程序的质量也在提高，越来越精确。

……但遗憾的是，自动翻译总会遇到极限，因此应当谨慎地看待，对于含有音乐专业术语的专业文本尤其如此。即便是人工翻译，也会出现进一步的问题，其根源在于本学科不同的教学惯例与传统。

在一段简短的导言中，我们（作为英语和德语的母语者）将说明三个特别困难的方面：

1. 有些英、德专业术语在对方语言中没有对应词。这种情况下无法给出正确的翻译，我们只能寄希望于英语能提供足够的清晰度，使含义得以理解。
2. 即便是最基础的概念，直译也可能无法涵盖其所有含义层次。幸运的是，德语和美式英语在这方面相对接近。可以想一想“quarter note”与“Viertelnote”的直接对应——这种对应在英式英语或法语中并不存在。
3. 此外还有一些特殊情况：有些术语乍看似乎是彼此对应，实际上用法不同。可能造成最大混淆、而且还极其常用的一个术语是“parallel”。在现代德语理论语言中，这个词用来描述共享同一组调号的大调与小调之间的关系（例如 C 大调和 a 小调），以及这些和弦本身之间的关系。在（英式与美式）英语中，这种关系被称为“relative”；而“parallel”指的是同一主音上的大调与小调之间的关系（例如同主音调 C 大调和 c 小调）。这当然只是一个例子，但与其他若干例子一样，它大概是最令人困惑的一个。

我们希望这些简短的提示对您有帮助，能帮助您从 OMT 中获益。

——Mark Gotham 与 [Andreas Feilen](https://www.musik.tu-dortmund.de/institut/personen/wissenschaftliche-mitarbeiterinnen-und-mitarbeiter/andreas-feilen/)

## 欢迎使用 Open Music Theory！

本教材用美式英语写成，但我们在世界各地都有读者和用户。我们虽然没有资源把教材详尽地译成多种语言，但如果国际用户能从现有内容中受益，我们非常高兴——音乐谱例对任何熟悉西方记谱法的人同样清晰可读，世界上越来越多的人英语越来越好，自动翻译的质量同样在不断提高。

但要提防自动翻译，对于像本书所用的音乐专业术语这样的专门语言尤其如此。而且无论是机器翻译还是人工翻译，不同语言的教学惯例之间都存在超出简单翻译的混乱差异。在这段简短的导言中，我们着重说明三个特别困难的方面。

1. 有些术语存在于德语中，但英语中没有对应词，反之亦然。这种情况下没有正确的译法，我们只能寄希望于从英语中能清楚地看出含义。
2. 即便是基础术语，也可能有着不同的组织方式，直译行不通。幸运的是，德语和美式英语在这方面相对接近。例如请注意“quarter note”与“Viertelnote”之间非常直接的对应。英式英语或法语则不然。
3. 最后还有一些特殊的陷阱：看起来相同的术语，实际用法却不同。这里最令人困惑、也最常用的术语大概是“parallel”。现代德语音乐理论教学用“Parallel”描述调号相同的两个调之间的关系（例如 C 大调和 a 小调），也用于描述这两个三和弦之间的同一关系。英语（英式与美式）音乐理论用“relative”表示这种关系，而用“parallel”表示同一主音上的调与三和弦（例如 C 大调和 c 小调，德语中称“Varianttonarten”）。这只是一个术语，但格外令人困惑，也牵连着更广泛的差异。

我们希望这些简短的提醒有用，您能从中受益于 OMT。

——Mark Gotham
