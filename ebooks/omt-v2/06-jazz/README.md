本部分向学生介绍传统爵士与布鲁斯中和声、节奏与即兴的基础。当然，和任何同样宽泛的体裁一样，爵士乐包含的音乐语言比这里呈现的更多，但学生将熟悉那些构成摇摆、比波普等子体裁的习语。

## 先修要求

本部分假定学生已熟悉[基础](../01-fundamentals/README.md)部分所涵盖的专题，以及[离调](../03-diatonic-harmony/15-tonicization.md)一章。

## 组织方式

第一章[摇摆节奏](01-swing-rhythms.md)向学生介绍摇摆音乐及其衍生的子体裁中常见的、风格性的节奏。

接下来，学生学习简单和复杂的[和弦符号](https://viva.pressbooks.pub/openmusictheory/chapter/lead-sheet-symbols/)，以及这些符号在爵士语境中如何以惯用方式[排列](03-jazz-voicings.md)。

随后几章讨论爵士曲目中常见的和声公式：[ii–V–I](04-ii-v-i.md)；[装饰和弦](05-jazz-embellishing-chords.md)，如副和弦和共同音减七和弦；以及[替换](06-substitutions.md)，如三全音替换、调式混合和以副和弦进行替换。

即兴在[和弦—音阶理论](07-chord-scale-theory.md)一章中讨论，该章也向学生介绍爵士音乐家如何用调式来即兴。

本部分最后几章涵盖传统布鲁斯的[形式/和声](08-blues-harmony.md)与[旋律](09-blues-melodies-and-the-blues-scale.md)方面。这也起到向下一部分[流行音乐](../07-popular-music/README.md)过渡的作用——流行音乐大量借用布鲁斯。
