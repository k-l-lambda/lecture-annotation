# 布鲁斯旋律与布鲁斯音阶

> **要点**
>
> - 在有歌词演唱的布鲁斯歌曲中，歌词由一行重复的句子加上一行对比的句子构成（**aab**）。旋律往往也遵循这一结构。
> - 布鲁斯旋律常常留下大段的空隙，以便旋律乐器与其他乐器之间进行呼应（call-and-response）。
> - 布鲁斯音阶就像一个加入额外半音经过音的小调五声音阶：*do–me–fa–fi–sol–te* $(\hat1-\downarrow\hat3-\hat4-\uparrow\hat4-\hat5-\downarrow\hat7)$。
> - 布鲁斯音阶可以轮转，从第二个音开始，形成大调布鲁斯音阶：*do–re–ri–mi–sol–la* $(\hat1-\hat2-\uparrow\hat2-\hat3-\hat5-\hat6)$。

本章讨论塑造了今日所知之布鲁斯的一些旋律趋势。作为例子，本文将以最早录制的布鲁斯歌曲之一——Clarence Williams 的「Gulf Coast Blues」为例，这首歌由商业上极为成功的布鲁斯歌手 Bessie Smith 于 1923 年录制。

## 乐句与歌词结构

许多布鲁斯音乐是唱出来的，因此歌词在这一体裁中扮演重要角色。构成 [12 小节布鲁斯](08-blues-harmony.md#12-bar-blues)的四小节乐句，通常配以具有 **aab** 结构的歌词：第一行陈述并重复（有时作些改动），第三行与之形成对比。Clarence Williams 的「Gulf Coast Blues」（1923）就是这样一个例子（谱例 2）。重复的歌词常常配上重复的旋律，模仿歌词的 **aab** 结构，不过在「Gulf Coast Blues」中并非如此。

| 结构 | 歌词 |
| --- | --- |
| a | The man I love, he has done left this town |
| a | The man I love, he has done left this town |
| b | And if it keeps on raining, I will be Gulf Coast bound. |

谱例 2. Clarence Williams 的「Gulf Coast Blues」的歌词。

布鲁斯乐句结构的另一个要素是呼应的概念，这一特征很可能继承自被奴役的非洲人和非洲裔美国人的工作歌。带歌词的人声旋律承担「呼」的角色，而器乐的填充承担「应」的角色。注意，在「Gulf Coast Blues」中，每个标为 **a** 的歌词都完全且仅仅在乐句的头两小节唱出。谱例 3 在「Gulf Coast Blues」的转写谱上作了标注，以显示这种呼应关系。

## 布鲁斯音阶

正如布鲁斯的和声往往不固守某一个自然音阶的调、无视调性音乐的规范，其旋律也同样以半音化与之相配。布鲁斯音阶记写在谱例 4 的上一行谱表中，它试图把布鲁斯的旋律实践概括为一个音阶，供初学的即兴者作为旋律的基础。布鲁斯音阶本质上是一个小调五声音阶，加上一个导向 *sol* $(\hat5)$ 的半音经过音。

🎼 [MuseScore 曲谱](https://musescore.com/user/32728834/scores/8515004)

谱例 4. C 布鲁斯音阶与 C 大调的 I 与 V 和弦造成风格上的冲突。

这个布鲁斯音阶既用于大调布鲁斯，也用于小调布鲁斯，尽管它与底层和声有冲突。当这一音阶与大调布鲁斯的和弦——I、V 和 IV，在 C 调中即 C 大三、F 大三和 G 大三——结合时，*mi/me* $(\hat3/\downarrow\hat3)$ 与 *ti/te* $(\hat7/\downarrow\hat7)$ 之间的典型冲突尤为显著。

这些冲突常常产生布鲁斯音（blue note）——既不是真正的降音也不是还原音，而是介于两者之间。布鲁斯音似乎是在 *mi/me* $(\hat3/\downarrow\hat3)$ 或 *ti/te* $(\hat7/\downarrow\hat7)$ 之间取折中。

### 「大调」布鲁斯音阶

有些即兴者觉得构想一个大调布鲁斯音阶会有帮助。大调五声音阶与小调五声音阶之间的差别，与大调布鲁斯音阶和小调布鲁斯音阶之间的差别完全相同：大调布鲁斯音阶是关系小调布鲁斯音阶的轮转。从 *me* $(\downarrow\hat3)$ 开始这个布鲁斯音阶，你就得到关系大调的布鲁斯音阶。这些关系总结在谱例 5 中。

🎼 [MuseScore 曲谱](https://musescore.com/user/32728834/scores/8515049)

谱例 5. 把布鲁斯音阶轮转，从它的第二个音开始，就得到大调布鲁斯音阶。

与小调布鲁斯音阶相比，大调布鲁斯音阶与大和弦的不协和程度较低。即兴时，在布鲁斯进行的各大和弦上用大调布鲁斯音阶来即兴，可能会有帮助。但请记住，在大和弦上使用（带降三音和降七音的）布鲁斯音阶，也是完全正常的做法。
