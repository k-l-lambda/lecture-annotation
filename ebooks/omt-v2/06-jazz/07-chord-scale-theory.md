# 和弦—音阶理论

> **要点**
>
> 和弦—音阶理论（Chord-Scale Theory）是一种把和弦与音阶联系起来的即兴方法。
>
> - 「和弦—音阶理论」这一名称来自这样一种想法：十三和弦的音可以重新排列成一个七音音阶。
> - 要确定和弦—音阶，先通过罗马数字分析找出调中心和和弦功能。
> - 罗马数字可以与调式编号对应。例如，如果一个和弦是大调中的 **ii** 和弦，就可以用**第二**调式（多利亚）来给这个和弦上色。
> - 演奏和弦—音阶时，把和弦音放在强拍上，使即兴旋律与和弦进行连接起来。
>
> *本书从许多不同角度讨论调式。关于调式的更多信息，参见[自然音阶调式导论（通论）](../01-fundamentals/15-intro-to-diatonic-modes-and-the-chromatic-scale.md)、[调式图式（流行）](../07-popular-music/13-modal-schemas.md)、[自然音阶调式（20—21 世纪）](../08-20th-and-21st-century-techniques/08-diatonic-modes.md)和[用调式、音阶与音集分析（20—21 世纪）](../08-20th-and-21st-century-techniques/10-analyzing-with-collections-scales-and-modes.md)。*

即兴演奏爵士的挑战之一，是在关注律动、互动和叙事形式的同时选择音高。和弦—音阶理论是一种在伯克利音乐学院及许多其他高校教授的方法，它使爵士即兴中的音高选择变得便利。和弦—音阶理论基于 George Russell 的《吕底亚半音调性组织概念》（*Lydian Chromatic Concept of Tonal Organization*，[1953] 2001），并由爵士教育家 Jamey Aebersold、David Baker 和 Jerry Coker 推广开来。

其基本概念是：每个和弦都来自一个母音阶；或者换个说法，进行中的每个和弦都可以用一个相关的音阶来上色。例如，延伸到十三音的 Dmi<sup>7</sup> 和弦由 D、F、A、C、E、G、B 组成，这些音与按三度叠置的 D 多利亚调式的音完全相同（谱例 1）。因此，在遇到和弦进行中的 Dmi<sup>7</sup> 和弦时，即兴音乐家可以选择用 D 多利亚调式的音来即兴，创作新的旋律。

## 基本的和弦—音阶关系

从大音阶的七个音上分别开始，就得到七种不同的调式。每种调式都有不同的半音与全音排列，因而色彩不同。（更多信息参见[自然音阶调式导论](https://viva.pressbooks.pub/openmusictheory/chapter/the-diatonic-modes/)和/或[自然音阶调式](../08-20th-and-21st-century-techniques/08-diatonic-modes.md)。）

由于 [ii–V–I 图式](04-ii-v-i.md)在爵士标准曲中如此常见，谱例 2 中的三种和弦—音阶关系通常最先教授。谱例 3 展示了这三种关系在 C 调 ii–V–I 进行中的运用。

| 和弦性质 | 调式 | 示例 |
| --- | --- | --- |
| 小七和弦 | 多利亚 | Dmi<sup>7</sup> = D 多利亚 |
| 属七和弦 | 混合利底亚 | G<sup>7</sup> = G 混合利底亚 |
| 大七和弦 | 伊奥尼亚 | C<sup>ma7</sup> = C 伊奥尼亚 |

## 把和弦—音阶用于调内进行

按和弦性质重新组织这些关系，就揭示了谱例 7 中为和弦性质匹配音阶的各种选择。例如，在小七和弦上即兴时，音乐家可以从三种和弦—音阶中选择：多利亚、弗里吉亚或爱奥利亚（谱例 8）。

| 和弦性质 | 音阶 |
| --- | --- |
| 小七和弦 | 多利亚、弗里吉亚、爱奥利亚 |
| 大七和弦 | 伊奥尼亚、吕底亚 |
| 属七和弦 | 混合利底亚 |
| 半减七和弦 | 洛克里亚 |

不过，重要的是要意识到，和弦—音阶理论并不意味着每次和弦变化时调都转调了。换句话说，这些和弦—音阶并不是调中心。由于每种调式暗示不同的延伸音，通过罗马数字分析确定和弦功能，有助于即兴者选择最契合调中心的和弦—音阶。

例如，[「Fly Me to the Moon」（1954）](https://open.spotify.com/track/2dR5WkrpwylTuT3jRWNufa?si=oQ--ro2iQ7GAjdV-HVkX_Q)的开头几小节，以五度圈的根音进行包含了七种自然音阶和弦—音阶关系中的六种（谱例 9）。这个例子中的和弦进行显然属于 C 调，而不是七个不同的调。与其简单用多利亚调式给每个小和弦上色、用伊奥尼亚调式给每个大和弦上色，不如区分 vi 和弦与 ii 和弦、I 和弦与 IV 和弦——这会得到一条听起来更自然的即兴线条。

## 和弦—音阶理论的局限

一些爵士教育家指出了和弦—音阶方法的局限，例如：

- **和弦之间缺乏声部进行。** 和弦—音阶理论可能让学生把每个和弦看作一个新的调中心，而不把整个和弦进行看作来自一个母音阶。这可能导致断断续续、缺乏旋律性、和弦之间没有平滑声部进行的即兴。
- **缺少比波普和布鲁斯风格中常用的半音化。** 和弦—音阶理论通常没有考虑 Charlie Parker、Dizzy Gillespie 和 Bud Powell 等比波普音乐家所用的辅助音、经过音、副导音和布鲁斯音（blue note）。
- **把 1960 年代的调式概念用于 1920—50 年代乐曲的时代错置。** Louis Armstrong 和 Charlie Parker 并不以和弦—音阶的方式思考。Hal Galper、Hal Crook 等教育家强调，在深入研究和弦—音阶关系之前，应先重视旋律装饰、和弦音即兴和布鲁斯风格的即兴。
- **回避口传传统。** 和弦—音阶理论强调眼和理智，而非耳朵和直觉。练习和弦—音阶关系，不能替代转写爵士即兴独奏、背谱、跟着录音即兴、与其他音乐家合奏等学习爵士即兴口传传统的首选方法。
