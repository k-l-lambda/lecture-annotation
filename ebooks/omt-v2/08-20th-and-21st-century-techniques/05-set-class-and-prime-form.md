# 集合类与原型

> **要点**
>
> - 集合类是一组通过移位或倒影相互关联的音级集合。
> - 集合类以其原型命名：把集合移位到零、并且（与它的倒影相比）向左最紧凑的那个版本。
> - 你可以用数学方法找出原型，也可以用钟面。
> - 所有可能的集合类都汇总在集合类表中，并且[在维基百科上](https://en.wikipedia.org/wiki/List_of_pitch-class_sets)以及许多其他网站上都能查到。

定义集合类的最简单方式就是“一组通过移位或倒影相互关联的音级集合”。这起初可能显得令人困惑，但它不过是另一种“类”而已。正如你在其他各章所学到的，“类”（class）是“组”的另一个名称。回想一下你已经学过的其他几种“类”。

- [音高与音级](02-pitch-and-pitch-class.md)：音高出现于具体的八度，我们常常还以具体的拼写来构想它。音级是*一组音高*，它们通过移位或倒影相互关联。
- [音程与音程级](03-intervals-in-integer-notation.md)：音程具有以半音计的具体距离，而音程级是*一组音程*，它们互为转位，或通过八度相互关联。

## 引言

**音级集合与集合类（音级集合类）** 是本章的主题。“集合类”的定义之所以显得更令人困惑，是因为它涉及两种“组”：类和集合。

- 类是某种方式上相互关联的一组事物。
- 集合是不一定以任何特定方式相互关联的一组事物。

打个比方，想想生物学对不同生物进行分类的方式。同一纲（class）中的植物都以特定的方式在生物学上相互关联：*被子植物纲*（*Angiospermae*）是一类会开花的植物。但我们也可以因其他理由把植物归到一组：例如某人前院里的那些植物。那是一组（set）植物，但不是一类（class）植物。

所以，音级集合是分析者出于某种理由决定放在一起的一组音高。音级集合类——这个术语十分笨拙，所以理论家们约定把它缩略为最后两个词，即“集合类”——则是这样一些“音高组”的组：它们全都通过移位或倒影相互关联。

### 为什么是移位和倒影？

分析大量后调性音乐的一种方式，是研究音级集合之间的[移位与倒影关系](04-pc-sets-normal-order-and-transformations.md)。看看下面的简短例子：巴托克（Béla Bartók）《主题与倒影》（“Subject and Reflection”）中的两个段落（谱例 1）。比较这两个段落，右手所包含的两个集合 [10, 0, 2, 3, 5] 与 [3, 5, 7, 8, 10] 通过 T<sub>5</sub> 相关联。左手那两个集合也以同样的方式关联。再看每个段落内部，右手与左手之间通过倒影相关联。在第一段中，它们通过 I<sub>8</sub> 关联；在第二段中，则通过 I<sub>6</sub> 关联。

要迅速解释这几小串音为什么听起来都一样，我们可以说**它们都是同一个集合类的成员。**

大、小三和弦也许是一个有帮助、也更为熟悉的例子。与音簇、四度和声、甚至增三和弦或减三和弦相比，大、小三和弦听起来都“一样”。原因就在于，所有大、小三和弦彼此之间都存在移位或倒影关系。

- 同一性质的三和弦通过移位相关联。
	- C 大三和弦 [0, 4, 7] 的 T<sub>2</sub> 是 D 大三和弦 [2, 6, 9]
	- A 小三和弦 [9, 0, 4] 的 T<sub>2</sub> 是 B 小三和弦 [11, 2, 6]。
- 相反性质的三和弦（大三和弦与小三和弦）通过倒影相关联。
	- C 大三和弦 [0, 4, 7] 的 I<sub>0</sub> 是 F 小三和弦 [5, 8, 0]。
	- C 大三和弦 [0, 4, 7] 的 I<sub>2</sub> 是 G 小三和弦 [7, 10, 2]。

## 原型

正如[音级集合以其常规形式命名](04-pc-sets-normal-order-and-transformations.md)一样，集合类以其原型命名：把集合移位到零、并且（与它的倒影相比）向左最紧凑的那个版本。

注意，原型只是集合类的一个标签。它并没有任何特殊地位——某位作曲家使用 [0, 1, 4] 作为音级集合，并不因为它的整数恰好与原型（014）相同而有什么特别意义。

### 数学过程

以下是把一个音级集合化为原型的步骤，并以谱例 1 中的动机为例。

| 步骤 | 示例 |
| --- | --- |
| 1. 把音级集合写成常规形式。 | [10, 0, 2, 3, 5] |
| 2. 移位该集合，使第一个音级为 0。 | T<sub>2</sub> = [0, 2, 4, 5, 7] |
| 3. 将第 2 步的结果倒影，并把结果写成常规形式。 | I<sub>0</sub> = [5, 7, 8, 10, 0] |
| 4. 移位第 3 步的集合，使第一个音级为 0。 | T<sub>7</sub> = [0, 2, 3, 5, 7] |
| 5. 比较第 2 步与第 4 步的集合。哪一个向左最紧凑，哪一个就是原型。把原型写在圆括号内，不加逗号。 | (02357) 就是原型（谱例 1）。 |
