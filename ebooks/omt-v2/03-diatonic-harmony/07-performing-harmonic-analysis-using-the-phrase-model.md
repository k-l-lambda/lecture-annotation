# 运用乐句模型进行和声分析

> **要点**
>
> 本章提供一套和声分析的策略：利用低音线对乐句中正在起作用的和声进行作出有根据的推测：
>
> 1. 通过聆听确定乐句的结尾。
> 2. 对每个乐句结尾的终止式进行和声分析。
> 3. 找出导向终止式的强前属和弦。
> 4. 回溯到乐句的开头，朝终止式方向分析。

## 概述

到目前为止，我们大多考察的是音乐的短小片断，关注作曲家如何在乐句中营造开始与结束的感觉。本章我们来看一个较长的乐句，它用到了我们迄今学过的一些和声，目的在于学习如何快速进行和声分析，并在分析中辨认出起作用的乐句模型。下面的视频课（谱例 1）演示了这一过程，其后是步骤大纲（以及一些提示）。

## 进行和声分析

1. 确定乐句的结尾。
	- 通常有助于聆听以下迹象：
		- 新乐句的开始，或前一乐句开头的重复。这告诉你一个“旧的”乐句必定刚刚结束。
		- 一种到达目标的感觉，往往由终止式标出。
2. 分析乐句的结尾。
	- 聆听，并在有终止式时标出它（通常都有）。
	- 对结尾进行和声分析：
		- 你知道，如果是半终止，乐句就结束在 V 上；如果是正格终止，乐句就以 V<sup>(7)</sup>-I 结束。在半终止处寻找低音中的 *sol*（$\hat{5}$），在正格终止处寻找低音中的 *sol*–*do*（$\hat5-\hat1$）。
			- 当心寻找 $(\mathrm{cad.^6_4})$，它常常出现在终止处。
3. 寻找强前属和弦。
	- 从终止式往回找强前属和弦。记住，强前属的低音通常是 *fa*（$\hat{4}$），不过 *re*（$\hat{2}$）也是可能的。
4. 从开头开始分析。
	- 运用你对主和弦延长的知识，看一看低音线，对你认为正在发生的主和弦延长作出有根据的推测。再清点每个低音上方和弦中的音，以核实你的推测是否准确。

## 在和声分析中辨认乐句模型

要辨认乐句模型在某个乐句中如何运作，我们可以套用从[和声、终止式与乐句结尾导论](01-intro-to-harmony.md)中学到的和声功能标记。每个乐句都要用一套（而且只有一套！）标记：**Tb–PD–D–Te**，即主开头（Tonic beginning，Tb）、前属（Predominant，PD）、属（Dominant，D）和主结束（Tonic ending，Te）。具体做法如下：

1. 定位乐句结尾。
	1. 给终止性的属和弦标上 **D**。
	2. 如果乐句以正格终止结束，给终止式的主和弦标上 **Te**。如果以半终止结束，可以省去这一标记。
2. 定位强前属和弦。
	1. **PD** 标在紧挨着终止性属和弦之前的第一个强前属和弦上（从左往右读）。
3. 标记开头的主和弦。
	1. **Tb** 标在开启乐句的主和弦上。乐句偶尔会推迟这个主和弦，甚至完全省略它。这种推迟或省略在浪漫主义音乐中更为常见。
