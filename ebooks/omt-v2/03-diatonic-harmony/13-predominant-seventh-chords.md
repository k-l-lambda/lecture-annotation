# 前属七和弦

> **要点**
>
> - 本章讨论前属七和弦 ii<sup>7</sup>、IV<sup>7</sup>、vi<sup>7</sup> 与 iii<sup>7</sup>。
> - ii<sup>7</sup> 及其转位是最常见的前属七和弦，谱例 2 显示 ii<sup>7</sup> 的哪些转位比另一些更常见。
> - 写作前属七和弦时，就和弦七音的处理而言有两条一般原则：
> 	- 用级进或共同音引入和弦七音。
> 	- 让和弦七音级进下行解决。

前面我们已看到，[给属和弦加上和弦七音](02-strengthening-endings-with-v7.md)如何增强了它走向主和弦的驱动力。在本章中，我们会看到，给前属和弦加上和弦七音也能取得类似的效果：它可以强化前属和弦进行到属和弦的动力（谱例 1）。给 ii 和弦加七音很常见；其他前属和弦（尤其是 IV 与 vi）也可以加七音，但没那么频繁。所有前属七和弦在处理和弦七音方面都遵循两条一般准则：

1. 和弦七音通常用级进或共同音引入。
2. 和弦七音级进下行解决。

## 给 ii 加和弦七音

谱例 2 按从最常见到最不常见的顺序列出了 ii<sup>7</sup> 的各种转位。我们下面逐一讨论。

| 常见程度 | ii<sup>7</sup> 的转位 |
| --- | --- |
| 最常见 | $\mathrm{ii^6_5}$ |
| 比较常见 | $\mathrm{ii^7}$ |
| 不太常见 | $\mathrm{ii^4_2}$ |
| 最不常见 | $\mathrm{ii^4_3}$ |

谱例 2. 按相对常见程度排列的 ii<sup>7</sup> 转位。

### ii$^6_5$

$\mathrm{ii^6_5}$ 常用来替代 $\mathrm{ii^6}$，也就是说，它常见于乐句接近结尾处（谱例 1）。除了常规的声部写作程序与和弦七音的处理之外，写作 $\mathrm{ii^6_5}$ 没有任何新的声部进行问题（谱例 3）。

### ii<sup>7</sup>

ii<sup>7</sup> 通常见于乐句接近结尾处（谱例 1）。除了遵循常规的写作程序与和弦七音的处理之外，写作 ii<sup>7</sup> 时要注意两个主要问题：

1. 这个和弦前面常常是主和弦，最好用 I<sup>6</sup> 而不是 I，以避免可能的平行进行；
2. 当 ii<sup>7</sup> 解决到 V<sup>7</sup> 时，ii<sup>7</sup> 或 V<sup>7</sup> 中必须有一个是不完整和弦，以避免造成声部进行问题（谱例 4）。

### ii$^4_2$

$\mathrm{ii^4_2}$ 通常在乐句开头通过进行 $\mathrm{I-ii^4_2-V^6_5-I}$ 来扩展主和弦（谱例 5）。如果你遵循常规的写作程序与和弦七音的处理，这个进行是容易写好的。

### ii$^4_3$

$\mathrm{ii^4_3}$ 相对少见。它出现时，通常是在乐句结尾代替强前属（谱例 6）。除了遵循常规的写作程序与和弦七音的处理之外，声部进行方面没有什么新东西要学。

## 其他前属七和弦

其余的前属七和弦——IV<sup>7</sup>、vi<sup>7</sup> 与 iii<sup>7</sup>——远不如 ii<sup>7</sup> 及其转位常见。其中，IV<sup>7</sup> 与 vi<sup>7</sup> 比 iii<sup>7</sup> 常见，这也说得通，因为 $\mathrm{iii}$ 作为三和弦本来就不太常见。IV<sup>7</sup> 与 vi<sup>7</sup> 在使用时往往都是原位和弦；而 vi<sup>7</sup> 只作为连接主区域与强前属区域的和声出现，而不用于阻碍进行（换句话说，V<sup>7</sup> 到 vi<sup>7</sup> 并不常见）。谱例 7 展示了涉及这些和弦的示例声部进行。它遵循常规的写作程序与和弦七音的处理。
