# 作为延长手段的 6/4 和弦

> **要点**
>
>  本章在[终止四六和弦](https://viva.pressbooks.pub/openmusictheory/chapter/endings-4-cadential-latexbeginsmallmatrix64endsmallmatrix-latex/)之外，再介绍三种 $^6_4$ 和弦。
>
> - 经过（pass.）$^6_4$ 的低音是一个经过音，并为一个 $^6_4$ 和弦配和声。它通常延长主和弦或前属和弦区域，并且总是出现在两个功能相同的和弦之间。
> - 辅助（n.）$^6_4$ 有一个静止的低音，上方声部中有两个作上辅助音运动。它通常延长主和弦或属和弦区域，其两侧的和弦总是原位。
> - 琶音（arp.）$^6_4$ 的低音琶音进行到和弦的五音，同时上方声部以某种方式保持和弦。它可以延长任何和声，我们在分析中通常不必费心去辨认它。
>
> 下面[谱例 6](#summary) 的表格总结了三种我们主张在分析中标出的 $^6_4$ 和弦各自的特点。

[本章播放列表](https://open.spotify.com/playlist/75asL58TBVx6tO01Nnu5py?si=59da5c1c8aa24790)

到目前为止我们看到，主（T）区域最常用属功能和弦来延长，尤其是转位的 $\mathrm{V^7}$。本章再来看一些不那么常见的延长方式，它们不仅可以延长主和弦，也可以延长属和弦和前属和弦。前文我们看到，$^6_4$ 和弦因为与低音之间含有一个不协和音（四度），所以受到特殊的处理。我们已经学过 [$\mathrm{cad.^6_4}$](05-cadential-64.md)；这里转向 $^6_4$ 和弦的另外三种用法：经过 $^6_4$、辅助 $^6_4$ 和琶音 $^6_4$。注意，分析时每当遇到 $^6_4$ 和弦，你都应当停下来辨认它是哪一种（终止、经过、辅助还是琶音），因为 $^6_4$ 的种类决定其标记。对 $^6_4$ 和弦来说，光有罗马数字还不够，还必须附上类型。

### 经过 $^6_4$

经过（pass.）$^6_4$ 是建立在低音经过音上的 $^6_4$ 和弦（谱例 1）。它最常见于延长主和弦或前属和弦的区域。重要的是，$\mathrm{pass.^6_4}$ 两侧的和弦总是同一功能（例如 $\mathrm{IV^6-pass.^6_4-ii^6}$），而不是不同功能（例如 $\mathrm{IV^6-pass.^6_4-I}$）。

谱例 1. 贝多芬钢琴奏鸣曲 Op. 14, no. 1 第一乐章第 50–57 小节中的 $\mathrm{pass.^6_4}$（[1:28-1:42](https://open.spotify.com/track/1TATwZjqU3I73RoGvWsVXA?si=c851bab266cd4f5b)）。

**谱例 2a** 演示了写作 $\mathrm{pass.^6_4}$ 以扩展主和弦的步骤，**谱例 2b** 和 **2c** 则展示了 $\mathrm{pass.^6_4}$ 延长前属区域的几种方式。注意，这些进行每一个也都可以反向使用（例如 $\mathrm{I^6-pass.^6_4-I}$ 同样可行）。

#### 用 pass$^6_4$ 写作：

1. **写出完整的低音。**你应当有三个级进移动的音，其中第一个和最后一个音属于同一功能区域（T 或 PD）。中间的音就是你的经过音。
2. **拼写 pass.$\mathbf{^6_4}$。**与 $\mathrm{cad.^6_4}$ 一样，要拼写 $\mathrm{pass.^6_4}$，需确定低音上方四度和六度是什么音。一个声部重复低音，正如 $\mathrm{cad.^6_4}$ 中那样。
3. **写出完整的高声部。**高声部应当是一条级进移动的线条，而不是静止线条。
4. **填充内声部，使它们尽量少动。**

### 辅助 $^6_4$

辅助（n.）$^6_4$ 由一个静止的低音构成，其上方有两个声部作上辅助音运动（谱例 3）。$\mathrm{n.^6_4}$ 有时被称为踏板 $^6_4$，这个名字反映了低音中的静止踏板音。它最常见于延长 I 或 V。**谱例 4a** 演示了写作 $\mathrm{n.^6_4}$ 以延长主和弦的步骤，**谱例 4b** 展示了延长 V 的声部进行。

谱例 3. 约瑟芬·朗《致国王之子》中的辅助 $\mathit{^6_4}$ 与琶音 $\mathit{^6_4}$。

#### 用 $\mathrm{n.^6_4}$ 写作：

1. **写出完整的低音。**低音将是同一个音的三个，通常是 *do*–*do*–*do* 或 *sol*–*sol*–*sol*（$\hat1-\hat1-\hat1$ 或 $\hat5-\hat5-\hat5$）
2. **拼写 n.$\mathbf{^6_4}$。**$\mathrm{n.^6_4}$ 位于中间的低音上。与 $\mathrm{cad.}$ 和 $\mathrm{pass.^6_4}$ 一样，确定中间低音上方六度和四度是什么音。一个声部重复低音。
3. **写出完整的高声部。** 对高声部来说，可以选上辅助音的线条，也可以选静止线条。与 $\mathrm{cad.}$ 或 $\mathrm{pass.^6_4}$ 不同，$\mathrm{n.^6_4}$ 的高声部更常是静止线条。
4. **填充内声部，使它们尽量少动。**

### 琶音 $^6_4$

琶音（arp.）$^6_4$ 通常产生于低音跳进到和弦五音、同时上方声部保持和弦的时候。它常见于例如终止处的低音琶音（谱例 3）或圆舞曲风格的伴奏（谱例 5）。与其他类型不同，$\mathrm{arp.^6_4}$ 通常不需要在分析中标出。谱例 5 用数字标出了它，但这样做并非必要——每个小节都可以直接标为 I。

| 6/4 和弦 | 标记 | 特点 |
| --- | --- | --- |
| 经过 | $\mathrm{pass.^6_4}$ |  |

- 低音经过音

- 外侧和弦功能相同``

| 辅助 | $x^{5-6-5}_{3-4-3}$ |  |

- 静止低音

- 两个上方声部作上辅助音运动

- 外侧和弦相同

| 终止 | $\mathrm{V}\begin{smallmatrix}(8-7)\\6-5\\4-3\end{smallmatrix}$ |  |

- 低音为 *Sol* $(\hat{5})$

- $^6_4$ 位于较强的拍上
