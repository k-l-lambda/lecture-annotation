# 用导音和弦在乐句开头作延长

> **要点**
>
> - 作曲家有时不用转位的 $\mathrm{V^7}$ 和弦来延长主和弦，而是用 $\mathrm{vii^{o7}}$ 或其转位。
> - $\mathrm{vii^{o7}}$ 的每个转位都可以按与 $\mathrm{V^7}$ 某个特定转位相同的方式使用。$\mathrm{V^7}$ 与 $\mathrm{vii^{o7}}$ 的配对依据是各自配和的低音。
> 	- $\mathrm{vii^{o7}}$ 可以用在任何能用 $\mathrm{V^6_5}$ 或 $\mathrm{V^6}$ 的地方。
> 	- $\mathrm{vii^{o}\begin{smallmatrix}6\\5\end{smallmatrix}}$ 或 $\mathrm{vii^{o6}}$ 可以代替 $\mathrm{V^4_3}$ 使用。
> 	- $\mathrm{vii^{o}\begin{smallmatrix}4\\3\end{smallmatrix}}$ 可以代替 $\mathrm{V^4_2}$ 使用。

## 概述

前文我们看到，[主和弦可以用](06-inverted-v7s.md)基本上四种进行来延长，我们按低音线对它们作了分类（回顾可参看[该章的总结部分](06-inverted-v7s.md#bass-line-summary)）。本章来看为这些同样的主和弦延长低音线配和声的另一种方式，所用的和声可以替代 V<sup>7</sup>：导音和弦。谱例 1 展示了莫扎特（Mozart）《羔羊经》（“Agnus Dei”）中的一段，用 vii<sup>o7</sup> 及其转位来延长主和弦。在实际版本下方，一个改写的版本表明，实际版本中的低音线也可以用 V<sup>7</sup> 及其转位来配和声。聆听时请留意两个版本在色彩上的差异。你或许会听出，实际版本充满一种美妙的紧张感，而改写的版本中这种紧张感要少得多。

谱例 1. 莫扎特《安魂曲》（*Requiem*）中《羔羊经》使用 vii<sup>o7</sup> 与 V<sup>7</sup> 的对比（[0:06–0:20](https://open.spotify.com/track/4HwQUYEHODAq2nr6ea2O7s?si=8D2dTz-0Svaw9BodLggqRg)）。

在讨论这种替代如何起作用之前，有三点需要强调：

1. 作为三和弦的导音和弦总是用第一转位 vii<sup>o6</sup>。这是因为其他任何转位都会与低音形成不协和，而作曲家往往避免这样。
2. 在小调中，要记住用 *ti* $(\uparrow\hat{7})$ 而非 *te* $(\downarrow\hat{7})$ 来构成导音和弦。换言之，记住升高导音。
3. 在大调中，导音七和弦如果不加改动，性质是半减七和弦（例如 C 大调中：B-D-F-A）。不过作曲家往往更偏爱全减七和弦的音响，所以我们几乎总是看到，大调中作曲家把和弦七音降低，使和弦成为全减七和弦（例如 C 大调中：B-D-F-A♭）（谱例 2）。两种都可以用，但 vii<sup>o7</sup> 比 vii<sup>∅7</sup> 常见得多，原因我们下面会看到。

## 用导音和弦替代 V<sup>(7)</sup>

$\mathrm{vii^{o7}}$ 的几乎所有转位（外加 $\mathrm{vii^{o6}}$）都能依据低音是哪个音，替代 $\mathrm{V^7}$（和 $\mathrm{V^6}$）的某个转位（谱例 3）。这意味着，举例来说，$\mathrm{vii^{o7}}$ 可以用在任何能用 $\mathrm{V^6_5}$ 或 $\mathrm{V^6}$ 的地方。类似地，$\mathrm{vii^{o}\begin{smallmatrix}6\\5\end{smallmatrix}}$ 或 $\mathrm{vii^{o6}}$ 可以代替 $\mathrm{V^4_3}$，$\mathrm{vii^{o}\begin{smallmatrix}4\\3\end{smallmatrix}}$ 可以代替 $\mathrm{V^4_2}$。

| 低音 | $\mathrm{V}^{7}$ | $\mathrm{vii}^{\circ7}$ |
| --- | --- | --- |
| ti（$\hat{7}$） | $\mathrm{V}\begin{smallmatrix}6\\5\end{smallmatrix}$ | $\mathrm{vii}^{\circ7}$ |
| re（$\hat{2}$） | $\mathrm{V}\begin{smallmatrix}4\\3\end{smallmatrix}$ | $\mathrm{vii}^{\circ}\begin{smallmatrix}6\\(5)\end{smallmatrix}$ |
| fa（$\hat{4}$） | $\mathrm{V}\begin{smallmatrix}4\\2\end{smallmatrix}$ | $\mathrm{vii}^{\circ}\begin{smallmatrix}4\\3\end{smallmatrix}$ |

谱例 3. 依据低音是哪个音，以 vii<sup>o7</sup> 替代 V<sup>7</sup>。

幸运的是，在声部写作方面没有太多别的东西要学。继续遵循通常的声部写作步骤，并按倾向解决上方声部中的活跃音。谱例 4 回顾了这些倾向，并加入了我们在属功能和弦中尚未见过的一个新音：*le*／*la* $(\downarrow\hat{6}$／$\hat{6})$。谱例 5 展示了涉及 vii<sup>o7</sup> 及其转位的主和弦延长，并把每一个与涉及 $\mathrm{V^7}$ 及其转位的相应延长作了比较。

| 活跃音 | 解决 |
| --- | --- |
| ti（$\hat{7}$） | do（$\hat{1}$） |
| re（$\hat{2}$） | do（$\hat{1}$） |
| fa（$\hat{4}$） | mi（$\hat{3}$） |
| le／la（$\downarrow\hat{6}$／$\hat{6}$） | sol（$\hat{5}$） |

## vii<sup>o</sup>4/2

你也许注意到，$\mathrm{vii^{o}\begin{smallmatrix}4\\2\end{smallmatrix}}$ 并不对应 $\mathrm{V^7}$ 的任何转位。这是因为它建立在 *le* $(\downarrow\hat{6})$ 上，而 *le* 并不属于 $\mathrm{V^7}$。$\mathrm{vii^{o}\begin{smallmatrix}4\\2\end{smallmatrix}}$ 是非常罕见的和声，因为从 *le* 下行到 *sol* $(\downarrow\hat6-\hat5)$ 的预期解决（见谱例 4）出现在低音中。到目前为止我们看到，低音中的 *sol* $(\hat{5})$ 通常支持 V 或 $\mathrm{V^7}$，这里也是如此：$\mathrm{vii^{o}\begin{smallmatrix}4\\2\end{smallmatrix}}$ 进行到 $\mathrm{cad.^6_4}$（谱例 6）。不过，$\mathrm{vii^{o}\begin{smallmatrix}4\\2\end{smallmatrix}}$ 并不是很常见的和弦。

## 把导音和弦用作半减七和弦

vii<sup>∅7</sup> 会带来 vii<sup>o7</sup> 所没有的声部进行难题，因为 *re* $(\hat{2})$ 与 *la* $(\hat{6})$ 之间是纯五度。这也许是作曲家偏爱 vii<sup>o7</sup> 而非 vii<sup>∅7</sup> 的另一个原因：用 ∅7 时，要当心平行五度，如谱例 7。避免平行五度的一个简便办法是，使用 vii<sup>∅7</sup> 或其转位时，始终确保 *re* $(\hat{2})$ 处于 *la* $(\hat{6})$ 之上。唯一无法照此办理的情况是 $\mathrm{vii^{∅}\begin{smallmatrix}6\\5\end{smallmatrix}}$，其中 *re* $(\hat{2})$ 在低音。虽然用 $\mathrm{vii^{∅}\begin{smallmatrix}6\\5\end{smallmatrix}}$ 也能避免平行进行，但我们建议干脆改用 $\mathrm{vii^{o}\begin{smallmatrix}6\\5\end{smallmatrix}}$ 或扩展 I<sup>6</sup>（如下文所示）。
