# 七和弦

> **要点**
>
> - 七和弦是四个音构成的、各音可以按三度排列的和弦。七和弦总能被"叠置"起来，使它的音要么全在线上，要么全在间上。
> - 当七和弦按三度叠置时，最低的音称为根音（root），下方中间的音称为三音（third），上方中间的音称为五音（fifth），最高的音称为七音（seventh），七音有时被称为"和弦七音"，以区别于音阶的第七级。
> - 常见的七和弦性质有五种：大大七和弦、大小七和弦、小小七和弦、半减七和弦和全减七和弦。
> - 七和弦还有另一种常见的命名方式：大大七和弦也常称为大七和弦，大小七和弦也常称为属七和弦，小小七和弦也常称为小七和弦，全减七和弦也常直接称为减七和弦。
> - 在大调和小调中，七和弦都具有与音级相对应的特定性质。这些性质在每一个大调和小调中都相同，因此值得记住。
> - 七和弦依据其根音、三和弦的性质与七度的性质、以及转位来识别。

本章我们聚焦于七和弦：四个音构成、各音可以按三度叠置的和弦。

## 七和弦

与三和弦一样，七和弦的各音总能按三度排列，位于谱表上相邻的线或间上。如果密集间距的三和弦看起来像一个雪人，那么密集间距的七和弦（如谱例 1 的第二小节）看起来就像一个加长版雪人，有一个下身、两个中身和一个头。

## 七和弦的性质与命名

谱例 3 列出了最常见的五种七和弦性质：大大七、大小七、小小七、半减七和全减七。这些性质由两个因素决定：

1. 由根音、三音和五音构成的三和弦的性质（见第二栏）
2. 根音到七音的七度的性质（见第三栏）

七和弦的和弦符号以三和弦根音的字母名称开头，其后标明其三和弦和七度的性质。不同性质七和弦的和弦符号示例见谱例 3 的最后一栏。[^1]

| 七和弦性质 | 三和弦性质 | 七度（音程）性质 | 和弦符号示例 |
| --- | --- | --- | --- |
| 大大七和弦（大七和弦） | 大三和弦 | 大七度 | F<sup>ma7</sup> |
| 大小七和弦（属七和弦） | 大三和弦 | 小七度 | F<sup>7</sup> |
| 小小七和弦（小七和弦） | 小三和弦 | 小七度 | Fmi<sup>7</sup> |
| 半减七和弦 | 减三和弦 | 小七度 | F<sup>∅7</sup> |
| 全减七和弦（减七和弦） | 减三和弦 | 减七度 | F<sup>o7</sup> |

谱例 3. 不同性质七和弦的命名总结。

对前三种七和弦性质来说，第一个词描述三和弦的性质，第二个词描述七度的性质：

- **大大**七和弦 = **大**三和弦 + **大**七度
- **大小**七和弦 = **大**三和弦 + **小**七度
- **小小**七和弦 = **小**三和弦 + **小**七度

另外两种性质都建立在减三和弦之上，但七度的性质不同：

- **半减**七和弦 = 减三和弦 + 小七度
- **全减**七和弦 = 减三和弦 + 减七度

音乐理论家常常使用上述名称，但这些和弦还有另一种常见的命名方式，见谱例 3 第一栏中的括号：

- 大大七和弦也常称为大七和弦。
- 大小七和弦也常称为属七和弦。
- 小小七和弦也常称为小七和弦。
- 全减七和弦也常直接称为减七和弦。
- 半减七和弦通常没有别的名称。

你的老师可能会要求你用其中一套术语、另一套术语，或者两套混用来标记这些和弦。

## 聆听七和弦

仔细聆听谱例 4 中不同性质的七和弦。在学习各种七和弦的音响时，人们常常把富于表现力的形容词与七和弦搭配起来。你也许会把大大七和弦想成"快乐而带爵士味"的，大小七和弦想成"未解决"的（好像它们强烈需要进行到另一个和弦），小小七和弦想成"悲伤而带爵士味"的，半减七和弦想成"可怕而带爵士味"的，全减七和弦则想成"非常可怕"的。

## 大调与小调中的七和弦性质

七和弦可以建立在大调音阶的任何音上。如谱例 6（G 大调）所示，建立在 *do* $(\hat1)$ 和 *fa* $(\hat4)$ 上的七和弦有大三和弦和大七度，而建立在 *sol* $(\hat5)$ 上的七和弦有大三和弦和小七度（属七和弦）。建立在 *re*、*mi* 和 *la* $(\hat2,\ \hat3,$ 和 $\hat6)$ 上的七和弦有小三和弦和小七度，而建立在 *ti* $(\hat7)$ 上的七和弦是半减七和弦——它们有减三和弦和小七度。这些七和弦性质在不同的调中不会改变；因此，记住这些性质非常有用。

## 拼写七和弦

要根据和弦符号构建七和弦，需要知道它的根音和性质——转位将在下一章[转位](https://viva.pressbooks.pub/openmusictheory/chapter/inversion-and-figured-bass/)中讨论。拼写七和弦的步骤与画三和弦的步骤相似。让我们从拼写大大七和弦开始：

1. 在谱表上画出根音。
2. 画出根音上方三度、五度和七度的音（即画一个"加长版"雪人）。
3. 想出（或写出）三和弦根音的大调调号。
4. 写出调号中适用于和弦各音的变音记号，构成大三和弦和大七度。

对于其他任何性质的七和弦，在需要时再加上额外的变音记号，改变和弦的三音、五音和/或七音。

谱例 8 展示了对 D 大大七和弦（D<sup>ma7</sup>）执行这一过程：

![谱例 8. 分四步拼写 D 大大七和弦。](../media/2020/05/dmaj.png)*谱例 8. 分四步拼写 D 大大七和弦。*

<!-- lilylet-begin: media/2020/05/dmaj.png -->
```lyl.play
\omit Score.TimeSignature \key c \major \time 4/4 \clef "treble" d1^\markup "1" | %1
<d f a c>1^\markup "2" | %2
\key d \major ^\markup "3" s1 | %3
\key c \major <d fs a cs>1^\markup "4" \bar "|" | %4
```
<!-- lilylet-end -->
1. 在谱表上画出和弦的根音 D。
2. 画出加长版雪人——F、A 和 C，即 D 上方的一般三度、五度和七度音。
3. 回想出 D 大调的调号。D 大调有两个升号：F♯ 和 C♯。
4. 在 F 和 C 左侧加上升号（♯），因为 F♯ 和 C♯ 在 D 大调的调号中。

下一个和弦的性质要求我们写出额外的变音记号，所以过程还要多几步。谱例 9 展示了对 A♭ 全减七和弦（A♭<sup>o7</sup>）执行的过程：

![谱例 9. 分六步拼写 A♭ 全减七和弦。点击放大。](../media/2020/05/abdim7.png)*谱例 9. 分六步拼写 A♭ 全减七和弦。点击放大。*

<!-- lilylet-begin: media/2020/05/abdim7.png -->
```lyl.play
\omit Score.TimeSignature \key c \major \time 4/4 \clef "bass" af,1^\markup "1" | %1
<af, c e g>1^\markup "2" \bar "||" | %2
\key af \major ^\markup "3" s1 \bar "||" | %3
\key c \major <af, c ef g>1^\markup "4" | %4
<af, cf eff g>1^\markup "5" | %5
<af, cf eff gff>1^\markup "6" \bar "|" | %6
```
<!-- lilylet-end -->
1. 写出 A♭，因为它是三和弦的根音。
2. 画出加长版雪人：加上 C、E 和 G，因为它们分别是 A♭ 上方的一般三度、五度和七度。
3. 回想出 A♭ 大调的调号。A♭ 大调有四个降号：B♭、E♭、A♭ 和 D♭。
4. 加上 E♭，因为它在 A♭ 大调的调号中。
5. 现在我们已按步骤拼写出了一个大大七和弦，但我们要的是全减七和弦，这意味着要加上不在 A♭ 大调调号中的变音记号：
	1. 把 C 和 E♭ 各降低半音到 C♭ 和 E𝄫，使三和弦从大三和弦变为减三和弦。
	2. 要把和弦的七度从大七度变为减七度，需要把它降低两个半音，从 G 降到 G𝄫。

对初学者来说，按这些步骤拼写七和弦是可靠的方法，但这一过程很耗时。如果你在乐器上练习弹奏所有性质的七和弦，直到熟练流畅，你对这些音的知识就会变得更加自动化，无需再走这个过程。

## 识别七和弦、重复与间距

与三和弦一样，七和弦也依据其根音、性质和转位来识别；转位在[转位](20-inversion.md)一章中讨论，所以这里的例子都采用原位。

1. 识别并写出它的根音。
2. 想象其根音的大调调号。
3. 识别并写出其三和弦的性质。
4. 识别并写出其七度的性质。

谱例 10. 一个待识别的原位七和弦。

要识别这个七和弦：

1. 由于和弦处于原位，根音就是最低的音 C♯。
2. C♯ 大调有七个升号（每个音都是升号）。在 C♯ 大调中 E 和 G 都应是升号，但我们看到这两个音都是还原的——被降低了半音——使三和弦成为减三和弦。
3. 和弦的七音 B 在 C♯ 大调中也应是升号，但这里它是还原的。把大七度缩小半音，它就变成了小七度。
4. 减三和弦与小七度构成半减七和弦；因此，这是 C♯ 半减七和弦（C♯<sup>∅7</sup>）。

如果七和弦的最下方音具有一个想象出来的调号（因为有一个重变音记号作用于它），就利用等音等价重新拼写这个七和弦，遵循[音程一章的最后一节](17-intervals.md#intervallic-enharmonic-equivalence)所述的过程。

与三和弦一样，七和弦的识别不受音的重复或开放间距（即使跨越多个谱号）的影响。谱例 11 展示了两个带重复、采用开放间距的不同七和弦。只需如前所述，把七和弦的各音想象或写成没有任何重复的密集间距，就能识别这些和弦。
