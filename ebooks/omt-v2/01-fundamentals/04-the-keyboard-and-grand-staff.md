# 键盘与大谱表

> **要点**
>
> - 弹钢琴将有助于你的音乐理论学习，因为它让你能以动觉的方式接触音乐。
> - 钢琴键盘上由两个和三个黑键组成的分组模式在七个八度上重复。
> - 白键 C 紧邻两黑键分组的左侧，白键 F 紧邻三黑键分组的左侧。
> - 钢琴演奏者（也称钢琴家）在大谱表上读谱。
> - 中央 C 是在大谱表两行谱表之间的那条线上出现的音符。
> - 在钢琴键盘上数音程时，总要把第一个音算作“一”。

许多学生发现，以动觉方式接触音乐后，学习音乐理论会更容易。换言之，通过演奏乐器（例如钢琴）实际制造声音，能帮助你更好地想象并内心听觉（audiate）你正在记写或学习的音乐。这使学生能更快地理解并“感觉”到不同音高之间的关系。

## 钢琴键盘

学习在钢琴上弹奏音符，是以动觉方式接触音乐的一种简便方法。你也许能在学校找到钢琴键盘（原声或电子的）。如果愿意，也可以买一台便宜的电子键盘。另一个选择是下载一款可以在手机上弹奏的免费钢琴应用，例如 [Tiny Piano](http://www.tinypiano.com/)。

在谱例 1 中，请注意键盘既有白键也有黑键。黑键被分成三个一组或两个一组。在谱例 2 中，请注意三黑键组和两黑键组在整个钢琴键盘上交替出现，每经过一个八度就重复这一模式。

## 弹钢琴

坐在钢琴前时，重要的是坐直，让头部处于双肩之上，双肩则应保持放松下沉。肘部应与身体保持舒适的距离，手指应保持拱形（就像伸手把图书馆的书从书架上取下来那样）。保持膝部与手腕灵活（不要僵硬），双脚平放在地上，除非你要用踏板。

谱例 3 说明了如何在钢琴前保持正确的姿势。

## 八度等价与钢琴键盘上的白键字母名

谱例 4 展示了一台钢琴键盘，并标出了白键音高的字母名。同样的字母名会出现在键盘的不同键上。正如[上一章](03-clefs.md)所讨论的，西方音乐记谱法中的音高用字母 A、B、C、D、E、F、G 表示，循环重复。由于西方体系中的八度等价原则，相隔一个八度的音具有相同的字母名。

![谱例 4. 标出白键音高字母名的键盘。](../media/2019/12/ch4-ex4-white_keys_labeled.jpg)*谱例 4. 标出白键音高字母名的键盘。*

在钢琴键盘上，当黑键以两个一组出现时，其左侧紧邻的白键是 C。当黑键以三个一组出现时，其左侧紧邻的白键是 F。

## 大谱表

钢琴音乐通常用高音谱号和低音谱号共同记写在大谱表上，如谱例 5 所示。要构成大谱表，就把带高音谱号的谱表放在带低音谱号的谱表上方。两行谱表在左侧用一条竖线和一个花括号连接。通常，钢琴家左手演奏较低的音（在低音谱号中），右手演奏较高的音（在高音谱号中）。

![谱例 5. 用竖线和花括号连接的大谱表。](../media/2019/11/brace_line-1.jpg)*谱例 5. 用竖线和花括号连接的大谱表。*

谱例 6 展示了大谱表上各线与各间，并标注了字母名。如你所见，高音谱号和低音谱号各线与各间的字母名与上一章（[阅读谱号](03-clefs.md)）所讲的一致。

![谱例 6. 标出各线与各间音高名称的大谱表。](../media/2019/12/ch4-ex6-grand_staff-labeled.jpg)*谱例 6. 标出各线与各间音高名称的大谱表。*

让我们仔细看看可能出现在高音谱表下方和低音谱表上方的加线音符。谱例 7 展示了其中一些音符，并标注了字母名。每一对上下并置的音是同一个音高，尽管它们是用两种不同的谱号记写的。（符干朝上的音符属于高音谱表，符干朝下的音符属于低音谱表。）

![谱例 7. 位于高音谱表下方与低音谱表上方的音高，并标注了字母名。](../media/2019/11/Screen-Shot-2019-11-23-at-11.48.12-AM.png)*谱例 7. 位于高音谱表下方与低音谱表上方的音高，并标注了字母名。*

<!-- lilylet-begin: media/2019/11/Screen-Shot-2019-11-23-at-11.48.12-AM.png -->
```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \omit Score.BarLine \key c \major \clef "treble" \stemUp d2^\markup "D" c^\markup "C" b^\markup "B" a^\markup "A" g^\markup "G" \\
\staff "2" \clef "bass" \stemDown d2_\markup "D" c_\markup "C" b_\markup "B" a_\markup "A" g_\markup "G" \undo \omit Score.BarLine \bar "|" | %1
```
<!-- lilylet-end -->
谱例 8 展示了把谱例 7 的谱表纵向压缩后的样子——如果大谱表的高音谱表与低音谱表之间没有那么大空隙，这些音符会是什么样子。谱例 8 中的字母名与谱例 7 相同。

![谱例 8. 纵向压缩后的大谱表，中央 C 被框出，写成一音双符干。](../media/2019/05/Screen-Shot-2019-05-30-at-2.03.57-PM.png)*谱例 8. 谱例 7 的谱表被纵向压缩，两个音符合并为一个（带两根符干）。*

<!-- lilylet-begin: media/2019/05/Screen-Shot-2019-05-30-at-2.03.57-PM.png -->
```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \omit Score.BarLine \key c \major \clef "treble" \stemUp d2 c b a g \\
\staff "2" \clef "bass" \stemDown d2 c b a g \undo \omit Score.BarLine \bar "|" | %1
```
<!-- lilylet-end -->

谱例 9 展示了一张纵向压缩的大谱表，并在音符 C 周围画了一个方框。这个被框住的 C 叫做中央 C，之所以这样称呼，是因为在谱例 9 所示的纵向压缩大谱表中，它位于高音谱表与低音谱表之间的中间位置。此外，中央 C 也是钢琴键盘上大致位于中间、通常在品牌名称下方出现的那个音。

![谱例 9. 纵向压缩的大谱表中，音符 C 被框出。](../media/2019/12/ch4-ex9-middle_c-1.jpg)*谱例 9. 纵向压缩的大谱表中，音符 C 被框出。*

<!-- lilylet-begin: media/2019/12/ch4-ex9-middle_c-1.jpg -->
```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \omit Score.BarLine \key c \major \clef "treble" s2 s2 \stemUp c2 d e \\
\staff "2" \clef "bass" \stemDown a2 b c s2 s2 \undo \omit Score.BarLine \bar "|." | %1
```
<!-- lilylet-end -->
谱例 10 展示了把谱例 9 纵向展开为常规间距的样子，中央 C 仍被框出。虽然它现在同时出现在高音谱表和低音谱表上，但这个音发声仍然是同一个音高。

![谱例 10. 纵向展开后的谱例 9。](../media/2019/11/vertically_expanded_example_9-revised.jpg)*谱例 10. 纵向展开后的谱例 9。*

<!-- lilylet-begin: media/2019/11/vertically_expanded_example_9-revised.jpg -->
```lyl.play

\staff "1" \omit Score.TimeSignature \omit Score.BarLine \key c \major \clef "treble" s2 s2 \stemUp c2 d e \\
\staff "2" \clef "bass" \stemDown a2 b c s2 s2 \undo \omit Score.BarLine \bar "|." | %1
```

## 一般音程（音程大小）

在音乐理论中，你常常需要测量或描述音符之间的距离——无论是在钢琴键盘上还是在谱表上。这种对钢琴键盘或谱表上音符的“数数”称为一般音程（generic interval）。数一般音程时，要知道第一个音应算作一，而不是零。谱例 11 在高音谱表的谱表上展示了两个音：F 和 C。如果你数谱例 11 中从 F 到 C 的音（数两个音之间的每条线和每个间），你可能会忍不住这样数：F 到 G 是一，G 到 A 是二，A 到 B 是三，B 到 C 是四。但这样是错的。你需要把 F 算作一，F 到 G 是二，G 到 A 是三，A 到 B 是四，B 到 C 是五。因此，我们会说 F 和 C 相隔五个音，而不是四个。音乐理论家和音乐家会把这两个音之间的距离称为“一般五度”。

![谱例 11. 一个一般五度的例子。](../media/2019/12/ch4-ex11-fifth.jpg)*谱例 11. 一个一般五度的例子。*

<!-- lilylet-begin: media/2019/12/ch4-ex11-fifth.jpg -->
```lyl.play
\omit Score.TimeSignature \omit Score.BarLine \key c \major \clef "treble" <f c'>1^\markup "5" | %1
```
