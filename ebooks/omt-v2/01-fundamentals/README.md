> *\* 交叉列出的章节*

本部分向学生介绍西方音乐记谱法的基础，包括节奏、音高与表情记号。学生还将学习构成和辨认基本的和声，包括音程（两音和声）、三和弦（三音和弦）和七和弦（四音和弦）。

## 先修要求

本部分假定学生此前并不熟悉西方音乐记谱法。不过，本部分每一章都假定学生已熟悉前面各章；因此，建议按顺序学习各章。

## 编排

在本部分第一章[西方音乐记谱法导论](01-introduction-to-western-musical-notation.md)中，鼓励学生思考自己会如何写下最喜爱的一首歌或一部作品。接下来的六章（[音符、谱号与加线的记谱](02-notation-of-notes-clefs-and-ledger-lines.md)到[记谱法的其他方面](07-other-aspects-of-notation.md)）关注音高的记谱，以及西方音乐记谱法的表情与风格惯例。

接下来，学生在随后四章中接触西方节奏记谱法的惯例（[记写节奏](https://viva.pressbooks.pub/openmusictheory/chapter/rhythmic-rest-values/)到[其他节奏要点](12-other-rhythmic-essentials.md)）。随后重新回到音高问题，从音阶、调号、自然音调式和半音音集的拼写与辨认讲起（见[大调音阶、音阶级数与调号](13-major-scales.md)到[自然音调式与半音“音阶”导论](15-intro-to-diatonic-modes-and-the-chromatic-scale.md)）。

其后的[视唱与听写基础](../14-ear-training/01-the-basics-of-sight-singing-and-dictation.md)一章，假定学生已掌握此前各章的概念。它既可以作为听觉训练课程的独立章节使用，也可以放在音乐理论课程或基础乐理课程的语境中使用。最后，本部分探讨和声的构成，从两音的[音程](17-intervals.md)讲到四音的[七和弦](19-seventh-chords.md)。

[三和弦](18-triads.md)与[七和弦](19-seventh-chords.md)两章不包含转位或通奏低音的内容，因为这些内容在单独的一章（[转位与通奏低音](https://viva.pressbooks.pub/openmusictheory/chapter/inversion-and-figured-bass/)）中讲述。这一章连同[罗马数字](21-roman-numerals.md)、[织体](08-texture.md)和[SATB 风格的和弦](23-chords-in-satb-style.md)，可以作为声部写作、对位、音乐欣赏或西方音乐史课程的入门材料。
