# 中音关系

> **要点**
>
> - 中音关系（mediant relationship）描述根音相隔三度（大三度或小三度）的和弦。
> - 中音关系和弦可分为三类：
> 	- 自然音中音（1 级）：两个共同音；和弦性质改变（大→小或反之）。两个和弦都属于同一自然音调。
> 	- 半音中音（2 级）：一个共同音；和弦性质不变（都是大和弦或都是小和弦）。两个和弦并不属于同一自然音调。
> 	- 双半音中音或不连续中音（3 级）：没有共同音；和弦性质改变（大→小或反之）。

 

上一章[新黎曼三和弦进行](12-neo-riemannian-triadic-progressions.md)的一个主要关注点，是根音相隔三度的三和弦之间的联系。例如，**L** 把 C 与 Emi 连接起来。看这些三度关系的和弦的另一种方式，是从中音关系的角度出发。回想[大调音阶](../01-fundamentals/13-major-scales.md)那一章：$\hat3$ 以及建立在它上面的三和弦（iii/III）有时被称为「中音」（mediant），而 $\hat6$ 及其三和弦（vi/VI）则是「下中音」（submediant）。但「中音」还有另一个更宽泛的含义：任何两个根音相隔三度的和弦。在这个意义上，iii 和弦与 vi 和弦（小调中的 III 与 VI）都是中音关系和弦。

不过，这些中音关系未必是自然音的。中音关系的全部可能组合可以分为三类：[^1]

- 自然音中音（1 级）：两个共同音；和弦性质改变（大→小或反之）。两个和弦都属于同一自然音调。
- 半音中音（2 级）：一个共同音；和弦性质不变（都是大和弦或都是小和弦）。两个和弦并不属于同一自然音调。
- 双半音中音或不连续中音（3 级）：没有共同音；和弦性质改变（大→小或反之）。

这些类别在谱例 1 中演示，并在下文各节中讨论。

谱例 1. 按类型划分的中音关系和弦一览。

## 自然音中音（1 级）

自然音中音共有两个共同音，并伴随三和弦性质的改变（在大调与小调之间），如 C 与 Ami，或 C 与 Emi。自然音中音可以[用新黎曼理论的术语](12-neo-riemannian-triadic-progressions.md)理解为构成 **L** 或 **R** 关系。[^2]

## 半音中音（2 级）

半音中音又远了一层：这一对和弦现在只有一个共同音，而且两个和弦的三和弦性质相同。例如，相对于 C 三和弦，半音中音是 E、E♭、A 与 A♭ 的大三和弦。这些三和弦由两个新黎曼变换联系起来：**L**／**R** 与 **P** 的各种组合。

一些英语文献给这四类中音关系附加了「上方降」、「上方升」、「下方降」、「下方升」的标签。上／下指中音关系和弦的根音在原和弦之上还是之下，降／升则说明半音中音和弦建立在哪个音阶级数上。德语理论用功能变换的术语来处理这些关系，如*Tonikavariantparallel*：即先改变主和弦的调式（大调变小调或反之），再在此基础上取（德语的）平行变换。

## 双半音中音（3 级）

在第三类、也是最后一类中，中音关系和弦没有任何共同音，三和弦性质也改变。从 C 大调出发，双半音中音是 E♭mi 与 A♭mi。这些和弦听起来彼此格外遥远。

## 小结 {#summary}

总的来说，中音关系可以说涵盖四个可能的和弦根音，每个根音上方可建大三和弦或小三和弦；由此产生八种可能的中音关系（4 个根音 × 2 种性质 = 8 个中音和弦）。下表以 C 大调为例归纳这八种情况：

| 根音／性质 | 大 | 小 |
| --- | --- | --- |
| E | 半音中音（2 级） | 自然音中音（1 级） |
| E♭ | 半音中音（2 级） | 双半音中音（3 级） |
| A | 半音中音（2 级） | 自然音中音（1 级） |
| A♭ | 半音中音（2 级） | 双半音中音（3 级） |

## 功能与变换

如前所述，在功能、术语与标签方面需要谨慎，因为并行存在着几套不同的惯例（这里的「并行」是个双关！）。最头疼的是「平行」（parallel）这个词：英语传统用它指同一根音上的两种调式（如 C 与 Cmi），而德语传统则用它指英语理论所说的「关系」（如 C 与 Ami）。很令人迷惑，对吧？尤其在处理历史文献和／或多语种文献时，务必当心。下表概述了功能标签（德语，以主音为出发点为例）以及[上一章](12-neo-riemannian-triadic-progressions.md)讨论过的组合式新黎曼变换（英语）。在德语一侧，「n/a」表示没有通用的术语或缩写。

| **和弦符号** | **中音类型** | **作为主功能使用时的现代德语（*Funktionstheorie*）术语** | **新黎曼变换** |
| --- | --- | --- | --- |
| Cmi | n/a | *Varianttonart*（t） | **P** |
| Ami | 自然音 | P. *Paralleltonart*（Tp） | **R** |
| Emi | 自然音 | G. *Gegenklang* 或 *Gegenparallel*（Tg，有时也作 Tl） | **L** |
| E | 半音 | *Tonikagegenparallel-Variante* | **LP** |
| E♭ | 半音 | *Tonikavariant-Parallele*（tP） | **PR** |
| A | 半音 | *Tonikaparallel-Variante* | **RP** |
| A♭ | 半音 | *Tonikavariant-Gegenparallele*（tG） | **PL** |
| E♭mi | 双半音 | n/a | **PRP** |
| A♭mi | 双半音 | n/a | **PLP** |
