# 八度的等分

在19世纪（甚至可以追溯到18世纪末），作曲家越来越热衷于在音乐中制造模糊性；避开那些明确确认调中心的进行，他们就得以挫败听众的期待。实现这种模糊性的一种办法，是使用和弦根音把八度等分开来的和弦进行。在纯粹的自然音体系中，和弦进行往往是不等分八度的——想想下行五度序列中的三全音跳进，或者上行级进序列中的半音，就可见一斑。在调性体系中，大调与小调音阶的不对称性把和弦与音阶级数拉向主音。反过来说，根音把八度等分的进行会很快把音乐带到自然音阶之外。例如，考虑以大三级进行的根音进行：C–E–G♯/A♭–C。建立在 C 音与 E 音上的和弦固然可以用 C 大调音阶内的和弦来配和声，但根音为 G♯/A♭ 的那个和弦却不能。再者，从 G♯/A♭ 到 C 的根音进行颠覆了定义调性体系的和声功能：这一和弦进行中根本不含任何属到主的运动。此类手法最早的例子，出现在较大作品的短小段落中，而作品其余部分仍遵循共性写作时期调性的规范。尽管如此，这些例子之所以值得注意，是因为它们预示了调性体系的松绑，为20世纪及以后走向新的音高组织体系的作曲实践开辟了道路。

## 等分八度的方法

只有*五*种方法可以把一个八度等分。这类根音进行分别按以下音程移动：

### 小二度

这多少有点琐碎，因为它不过是产生半音阶而已。不过，确实存在根音按上行或下行小二度移动的和弦进行。

### 大二度

有大量音乐是用全音音阶写成的，全音音阶把八度等分为大二度。这类音乐大多不是调性的，甚至不是三和弦性的。只有少数例子中，三度叠置和弦的根音构成全音音阶。

### 小三度

按小三度进行的根音构成减七和弦。这类和弦进行最常见于如下情况：构成八度等分的每一个根音都被离调，或者被插入其间的和弦隔断。较为少见的情况是，构成等分的根音紧接着依次呈现。这类进行也与八声音阶（octatonic scale）有关联，八声音阶包含相互重叠的减七和弦。

### 大三度

根音按大三度移动的和弦进行，会构成增三和弦。这类和弦进行既见于和弦紧接呈现的例子，也见于中间有插入和弦的例子。这些进行与六声音阶（hexatonic scale）密切相关，六声音阶包含两个相互重叠的增三和弦。

### 三全音

等分八度的最后一种方法是通过三全音。这样做出来的和弦进行无非就是两个和弦，所以曲目中的实例多少有些琐碎。

当然，你还可以用其他音程，比如纯四度和纯五度，做出根音持续移动的和弦进行。它们会制造调性模糊，但不会像上面列出的五种那样，在一个八度之内走完一圈。
