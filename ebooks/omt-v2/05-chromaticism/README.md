本部分涵盖半音和声中常被讨论的主题，包括[调式混合](01-modal-mixture.md)、[那不勒斯和弦](02-bii6.md)与[增六和弦](03-augmented-sixth-chords.md)，以及[共同音和弦](04-common-tone-chords.md)。其余各章则深入探讨较为专门的主题，这些主题可能会出现在专门讲授半音和声以及19世纪与20世纪初音乐的进阶课程中。

## 先修知识

本部分假定读者熟悉[基础乐理](../01-fundamentals/README.md)部分所涵盖的主题，以及[自然音和声、离调与转调](../03-diatonic-harmony/README.md)部分的各章内容。

## 结构安排

第一章[调式混合](01-modal-mixture.md)向学生介绍从同主音调式借用的音阶级数与和弦这一概念。这一章应视为本部分后续各章的基础。

接下来，学生学习西欧共性写作音乐中最常见的半音前属和弦：[那不勒斯和弦](02-bii6.md)与[增六和弦](03-augmented-sixth-chords.md)，以及这些和弦在这一曲目中的惯用行为。随后讨论[非功能性的减七和弦与增六和弦](04-common-tone-chords.md)，这一讨论建立在学生此前各章学到的、这些和弦在功能语境中的知识之上。

[和声省略](05-harmonic-elision.md)教学生如何解决属和弦与减七和弦，使解决过程抑制或去掉一个期待中的和弦，代之以一个与之相似、但功能上不同于原和弦的和弦。这一章可以紧接着[离调](../03-diatonic-harmony/15-tonicization.md)的各章来讲，而且它对本部分后面[半音序列](09-chromatic-sequences.md)一章是特别有用的预备。

关于[重新解释增六和弦](06-reinterpreting-augmented-sixth-chords.md)与[重新解释减七和弦](https://viva.pressbooks.pub/openmusictheory/chapter/reinterpreting-diminished-seventh-chords/)的两章，是讨论远关系转调与音乐中和声模糊性的入口。这两章要求读者牢固掌握前面介绍这些和弦的入门各章。鉴于增三和弦本身固有的模糊性，[增三和弦的多种可能](07-augmented-options.md)一章紧随其后顺理成章，同时也充当通往[八度的等分](08-equal-divisions-of-the-octave.md)讨论的过渡。

[半音序列](09-chromatic-sequences.md)、[平行半音序列](https://viva.pressbooks.pub/openmusictheory/chapter/parallel-chromatic-sequences/)与[综合进行](10-the-omnibus-progression.md)三章合在一起，可以构成一个关于半音音乐中和声模式重复的小单元，并回顾此前学过的自然音序列知识。在这些章节之前先讨论[八度的等分](08-equal-divisions-of-the-octave.md)，可以为此类进行的整体音响提供更多背景。

[变化与扩展的属和弦](11-altered-and-extended-dominant-chords.md)一章向学生介绍比七和弦「更高」的和弦，以及变化和弦音（例如降低或升高五音）的概念。这一章可以延伸为对本书另一处讲述的[爵士和声](../06-jazz/README.md)的讨论，也为围绕这些和弦在这两种迥然不同的曲目中的用法展开有趣的讨论提供了机会。

[新黎曼三和弦进行](12-neo-riemannian-triadic-progressions.md)一章给学生提供了分析具有非功能三和弦进行的半音音乐所必需的工具，也让他们能创作不遵循功能调性规范的、有趣的半音进行。这一章无论是作为半音和声单元或课程的总括，还是作为20世纪与21世纪音乐课程的一部分，都同样有用。[中音关系](13-mediants.md)一章则进一步阐述根音相隔三度的和弦。
