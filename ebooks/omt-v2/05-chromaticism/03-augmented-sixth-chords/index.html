    增六和弦¶

    要点

    • 增六和弦是一类半音前属和弦，其共同特征是包含 le 与 fi \((\downarrow\hat6-\uparrow\hat4)\) 之间的增六度音程。
    • 增六和弦有意大利增六和弦（It+6）、法国增六和弦（Fr+6）和德国增六和弦（Ger+6）。
    • 增六和弦没有根音，它们解决到原位的属和弦。

    简要概述¶

    增六和弦是一类半音前属和声，其名称来源于它们包含一个非常特殊的音程：le 与 fi \((\downarrow\hat6–\uparrow\hat4)\) 之间的增六度。每一种增六和弦（意大利、法国和德国）在这一音程之外还含有一个或两个其他音级，如下表所概括，并在谱例 1 中加以说明。增六和弦在大调和小调中都能出现，但在小调中更为常见。

    +6 类型 音级 唱名
    意大利 \(\hat{1}\) do
    法国 \(\mathrm{\hat1\ and\ \hat2}\) do 与 re
    德国 \(\mathrm{\hat1\ and\ \downarrow\hat3\ (or\ \hat1\ and\ \uparrow\hat2)}\) do 与 me（或 do 与 ri）

    语境¶

    你现在已经熟悉了为罗马数字分析寻找和弦根音的过程，但增六和弦通常不按根音分类。相反，它们被认定为含有 le 与 fi \((\downarrow\hat6–\uparrow\hat4)\) 之间增六度的和弦，并进一步根据和弦中的其他音分类，如上所示。"意大利""法国""德国"这些名称更多是色彩性的，而非历史性的，但每一种和弦都以这一特征音程为基础。

    谱例 2. 增六度音程的标准声部进行。

    增六和弦是用半音化制造和声紧张的另一种策略。它们大多用作前属和声（不过也可以起装饰作用——见共同音和弦），并在终止点上直接引向原位 V。它们可以加强向半终止和正格终止推进的力度，V 和弦可以带七音和/或包含 \(\mathrm{cad.^6_4}\)。谱例 3 展示了三种类型在简单终止语境中的用法（正格终止版本）。注意，可以预期 le \((\downarrow\hat6)\) 会是该和弦的低音，但 fi \((\uparrow\hat4)\) 可以出现在任何其他声部。Ger+6 之后通常接 \(\mathrm{cad.^6_4}\)，用以抵消 G–D 与 F♯–C♯ 之间本会出现的平行纯五度；\(\mathrm{cad.^6_4}\) 也可以跟在其他类型之后。在四声部织体中，Fr+6 和 Ger+6 不需要重复任何一个音；在只有三个不同音高的 It+6 中，通常会重复主音，因为它不是活跃的音。

    与哀歌低音进行的联系¶

    分析时如何辨认增六和弦¶

    由于增六和弦并不像你习惯了的那样以根音为基础，你需要另一种策略来找到它们。若试图按三度叠置来确定其性质，会变得令人困惑，因为其中会包含一个减三度。最简单的方法就是记住：低音 le–sol \((\downarrow\hat6-\hat5)\) 的进行可以支撑这种进行；如果这些音级上方有和弦，并且含 le \((\downarrow\hat6)\) 的那个和弦还含有 fi \((\uparrow\hat4)\)，那么你很可能就找到了一个增六和弦。接下来，只需查看其余和弦音，确定具体类型（意大利、法国或德国）。

    大调中的 Ger+6：me 还是 ri \((\downarrow\hat3\) 还是 \(\uparrow\hat2)\)¶

    当 Ger+6 用于大调时，常把 me \((\downarrow\hat3)\) 改写为另一种拼写，以避免连续两次写出同一个音名却带不同的变音记号，因为 Ger+6 通常解决到 \(\mathrm{cad.^6_4}\)，而后者已经含有 mi \((\hat3)\)。用 ri \((\uparrow\hat2)\) 代替 me \((\downarrow\hat3)\) 也能更清楚地表明该线条的上行运动。谱例 5 展示了 Ger+6 的这种变体拼写。

    德国减三和弦¶

    19世纪，作曲家们引入了 Ger+6 的一种变体，把 fi \((\uparrow\hat4)\) 而非 le \((\downarrow\hat6)\) 放在低音（谱例 6）。这使增六度音程转位，从而变成减三度。Gero3 与 viio7/V 非常相似——唯一的区别是 Gero3 含有 le \((\downarrow\hat6)\)，而 viio7/V 含有 la \((\hat6)\)——并且两者都解决到原位 V。

    音乐实例¶

    Ernesto Nazareth 的探戈"Remando"（谱例 7）在第 60 小节把 Ger+6 用作终止进行的一部分。注意从该小节开始级进下行的低音进行 la–le–sol \((\hat6-\downarrow\hat6-\hat5)\)，这是一种在低音中以级进接近增六和弦的手法。这支舞曲的旋律有许多重音经过音，因此在这一语境下，Ger+6 期间的 C♯ 应视为装饰音。正如 Ger+6 的典型情况，其后的属和弦以 \(\mathrm{cad.^6_4}\) 加以装饰。
