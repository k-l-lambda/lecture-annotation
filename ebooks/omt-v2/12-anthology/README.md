虽然严格来说没有先修要求，但这些选集章节显然与特定的教材章节相关。这里始终会标明最相关的教材章节，方便你在教材与选集之间来回对照阅读。

## 编排方式

各章分别关注：

1. 调性（主要是半音）和声。该章的各小节提供增六和弦、那不勒斯和弦等具体和弦的实例，并附有可在线播放、下载等的乐谱链接。
2. 值得注意的节拍概念
3. 曲目中的十二音音列
