Punctum contra punctum……点对点……音对音。

本节讨论的“对位”（counterpoint）把这一术语理解为音的一般结合。尽管“对位”有时被用来说明和声之“纵向”方面的“横向”或“旋律”补充，但在实践中二者显然并不那么容易分开，因此我们在这里并不打算作任何这样截然的区分，只是强调线性要素。

本节还着重安排了“自己动手”的练习，包括类别对位练习，以及 16、18 世纪风格的拟作，其中包含富克斯（Fux）第一部分全部习题的数字版本。

## 先修知识

《开放音乐理论》这第二部分假定读者具备[基础](../01-fundamentals/README.md)知识，但不涉及后面各部分的内容。

## 组织方式

本节涵盖历史上用于对位教学的一些主要曲目类型与技法：

- 我们从大概最著名的、所谓[类别对位](01-species-counterpoint.md)方法（富克斯之后）开始。
- 类别对位有时会与[16 世纪的模仿复调风格](08-16th-century-contrapuntal-style.md)混为一谈，因此在关于类别的各章之后，我们再进一步细看那一曲目。
- 16 世纪复调可以看作另一种模仿风格的先声：[赋格](09-high-baroque-fugal-exposition.md)。这里我们专门考察 18 世纪早期赋格的开始部分。
- 最后，仍留在 18 世纪，我们离开严格模仿，来看一些与对位思维相关的其他路子，尤其是[加朗特图式](11-galant-schemas.md)的实践：一些短的、预先存在的声部结合模板，它们可以发展成“真正的”音乐（创作或即兴）。
