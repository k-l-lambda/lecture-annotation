# 《帕纳索斯阶梯》练习

前几章介绍了类别对位，以及那部关于定旋律写作的经典教学论著——约翰·约瑟夫·富克斯（Johann Joseph Fux）的《帕纳索斯阶梯》（*Gradus ad Parnassum*，1725）。本页提供该论著中全部的定旋律练习，供你动手尝试富克斯式的类别对位。

《帕纳索斯阶梯》分为三个部分：

1. **二声部**（46 条练习）
2. **三声部**（44 条练习）
3. **四声部**（32 条练习）

针对上述每个部分，我们提供四种文件：

1. **练习**（Exercises）：全部定旋律练习，只给出定旋律，其余声部留空，由你完成。
2. **解答**（Solutions）：富克斯为这些练习给出的全部答案，即定旋律加上富克斯写出的其他声部。
3. **标注**（Annotations）：在上述解答上标出每个附加声部中的每个音与定旋律声部所构成的音程。
4. **独立定旋律**（Distinct）：所有声部中每一条互不相同的定旋律。全部练习都以这一格式为基础，所以这些简洁的文件把全部可能性提炼了出来：你可以用这个文件，对任何一条定旋律、在任何声部配置下做任何类别的练习。

所有文件都以可编辑格式提供，教师可以自由调整、组合练习，以满足自己班级的需要。具体来说，文件提供以下格式：

- .mxl：可在任何制谱软件中打开，如 MuseScore、Sibelius 或 Finale
- .mscz：专用于 MuseScore，保留全部原始排版
- .pdf
