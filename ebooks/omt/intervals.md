# 音程与二音和弦

*音程*（interval）是两个音高之间的距离，通常以音阶上的级数来衡量。

*二音和弦*（dyad）是同时发响的一对音高（换言之，一个由两个音构成的和弦）。由于二音和弦是由其两个音高之间的音程来界定的，二音和弦常常就被简单地称为音程。

因此，*音程*一词通常既指音阶上两个音高之间的距离，也指两个音高相隔该距离的二音和弦。

### 半音音程

衡量音程最简单的方法，尤其是在键盘上，是数两个音高之间有多少个半音（half-steps，或称 *semitones*）。例如，要确定 C4 与 E4 之间的半音音程（chromatic interval），就从 C4 出发，沿半音阶上行到 E4，一路数过去：C#4、D4、D#4、E4。E4 比 C4 高四个半音。半音音程的记法是：小写字母 **i** 后接表示半音数的阿拉伯数字。C4–E4 是四个半音，即 **i4**。

### 自然音音程

在调性音乐中，我们更常关心的是自然音（大调或小调）音阶上的级数。这有点棘手——不是因为它难，而是因为它违反直觉。遗憾的是，这一体系太古老、太根深蒂固，现在已经无法改变了！不过，一旦你度过了最初的陌生感，自然音音程（diatonic intervals）并不难掌握。

在识别一个自然音音程时，先*只看字母名称*。也就是说，暂时把 C、升 C 和降 C 都当作 *C*。然后，数出所讨论的两个音高之间有多少级（不同的字母），*计数时把两个音高都算进去*。这样就得到了*一般音程*（generic interval）。

例如，从 C4 到 E4，把 C 和 E 都算进去，共有三个自然音级（三个字母名称）：C、D、E。因此，C4–E4 的一般音程是*三度*。任何 C 到任何 E 都是如此：C#4 到 E4、Cb4 到 E#4，等等。它们都是自然音三度。

我们常常需要比一般音程更具体的信息。这种具体性体现为音程的*性质*（quality）。把*性质*与一般音程名称结合起来，就得到*具体音程*（specific interval）。

音程的性质有五种：

- 增（A）
- 大（M）
- 纯（P）
- 小（m）
- 减（d）

要得出一个音程的性质，需要同时找出一般音程和半音音程。然后查阅下表，找出具体音程。

|  | 同度 | 二度 | 三度 | 四度 | 五度 | 六度 | 七度 | 八度 |
| --: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| i0 | P1 | d2 |  |  |  |  |  |  |
| i1 | A1 | m2 |  |  |  |  |  |  |
| i2 |  | M2 | d3 |  |  |  |  |  |
| i3 |  | A2 | m3 |  |  |  |  |  |
| i4 |  |  | M3 | d4 |  |  |  |  |
| i5 |  |  | A3 | P4 |  |  |  |  |
| i6 |  |  |  | A4 | d5 |  |  |  |
| i7 |  |  |  |  | P5 | d6 |  |  |
| i8 |  |  |  |  | A5 | m6 |  |  |
| i9 |  |  |  |  |  | M6 | d7 |  |
| i10 |  |  |  |  |  | A6 | m7 |  |
| i11 |  |  |  |  |  |  | M7 | d8 |
| i12 |  |  |  |  |  |  | A7 | P8 |

例如，C4–E4 是一般三度，其半音音程为 i4。包含四个半音的三度是*大三度*（M3）。请注意，要找出具体音程，一般音程和半音音程两者缺一不可，因为每个一般音程、每个半音音程都对应着多个具体的自然音音程。

请注意，有些一般音程可以是增、纯或减，另一些则可以是增、大、小或减。没有哪个一般音程既可以是大/小，又可以是纯；如果它可以是大或小，就不可能是纯；如果它可以是纯，就不可能是大或小。一个音程的增音程形式总是比大音程或纯音程宽一个半音；减音程总是比小音程或纯音程窄一个半音。

唱名也有助于确定具体音程。每一对唱名音节，无论在什么调中，只要清楚哪个音节是较低的音、哪个是较高的音，其音程都是相同的。记住各对唱名之间的音程，可以加快你分析音乐中出现的二音和弦的速度。例如，知道 *do*–*mi*、*fa*–*la* 和 *sol*–*ti* 总是大三度，知道 *re*–*fa*、*mi*–*sol*、*la*–*do* 和 *ti*–*re* 总是小三度，就能更快地分析大调中的二音和弦。

### 复音程

上面讨论的从同度到八度的音程，称为*单音程*（simple intervals）。任何大于八度的音程都被视为*复音程*（compound interval）。以 C4 到 E5 的音程为例。它的一般音程是十度。然而，在几乎所有音乐情境中，它的作用都与 C4 到 E4 相同。因此，十度 C4–E5 也称为*复三度*（compound third）。复音程的性质与相应的单音程相同。如果 C4–E4 是大三度，那么 C4–E5 就是大十度。

### 音程转位

除了 C4–E4 和 C4–E5 之外，E4–C5 也有着相似的声音和音乐功能。事实上，任何保持相同的两个音级、只改变音区的二音和弦，都会有相似的声音和功能。然而，E4–C5 的最低音是 E 而不是 C，这意味着它的一般音程不同：E4–C5 是六度，而不是三度。由于这一差别，它在某些情况下也会起不同的音乐作用。不过，两者之间的关系是无法回避的。

由相同的两个音级构成、但上下位置的音级互换的二音和弦，被称为互为*转位*（inversions），因为其中的音级被*倒置*（inverted）了。同样，这些转位二音和弦所划定的音程，也被称为互为*转位*。

再以 C4–E4（大三度）和 E4–C5（小六度）为例。这两个二音和弦有相同的两个音级，但一个是 C 在下、E 在上，另一个是 E 在下、C 在上。因此，它们互为转位。

![转位关系：大三度与小六度](assets/intervals/inversion.png)

这两个二音和弦所体现的三种关系，对所有音程转位都成立。

第一，两者的半音音程相加等于 12。（C4–E4 = i4；E4–C5 = i8；i4 + i8 = i12）这是因为两个音程相加构成一个八度（在 E4 处重叠）。

第二，*两个一般音程的数值相加等于九*（三度加六度，即 3 + 6）。这是因为两个音程相加构成一个八度（8），而把它们加在一起时，其中一个音被计算了两次。（请记住自然音音程那种违反直觉的计数方式：数字包含起始音和结束音；而把互为转位的音程合在一起时，总有一个音被计算两次——在这个例子中是 E4。）

最后，大音程转位后成为小音程，反之亦然。这对音程转位总是成立。同样，增音程的转位总是减音程，反之亦然。纯音程的转位总是纯音程。

> 大 ↔ 小  
增 ↔ 减  
纯 ↔ 纯

音程转位现在看起来也许令人困惑、晦涩难懂，但它将是学习声部进行和学习和声时一个极其重要的概念。

### 旋律音程与和声音程

最后一个需要注意的音程类型区分，是*旋律*音程与*和声*音程。这一区分很简单。如果一个二音和弦的两个音高同时发响（一个由两个音构成的和弦），它们之间的音程就是*和声音程*（harmonic interval）。如果所讨论的两个音高先后相继发响（如在旋律中），它们之间的音程就是*旋律音程*（melodic interval）。这一区分在声部进行中很重要，因为在和声语境与旋律语境中，被偏爱或被禁止的音程是不同的。这一区别对于听辨也很重要，因为听辨相同性质的旋律音程与和声音程需要不同的技巧。

### 协和与不协和

音程被分为*协和*（consonant）或*不协和*（dissonant），依据是它们的声音（听起来有多稳定、甜美或刺耳）、它们有多容易唱，以及它们在一段音乐中最适合发挥的作用（开头、中间、结尾；位于某些其他音程之间；等等）。旋律与和声适用不同的标准。以下分类对于你的严格声部进行练习至关重要，对于自由创作和编配工作也会是有益的指导。

**旋律上的协和与不协和**

以下*旋律*音程是*协和*的，在严格声部进行中，既可以用于相继的音高，也可以作为同一方向级进进行的边界：

- 所有纯音程（P4、P5、P8）  
- 所有自然音级进（M2、m2）  
- 大三度和小三度  
- 大六度和小六度

所有其他*旋律*音程都是*不协和*的，必须避免用于相继的音高，也必须避免作为同一方向级进进行的边界，包括：

- 所有增音程和减音程（包括与协和音程等音的音程，如 A2 和 A1）  
- 所有七度

**和声上的协和与不协和**

以下*和声*音程是*不完全协和音程*（imperfect consonances），在严格声部进行中可以相对自由地使用（开头和结尾除外）：

- 大三度和小三度  
- 大六度和小六度

以下*和声*音程是*完全协和音程*（perfect consonances），在严格声部进行中必须在有限的情况下谨慎使用：

- 所有纯音程，*纯四度除外*（P1、P5、P8）

所有其他*和声*音程都是*不协和*的，在严格声部进行中必须以非常特定的方式使用，包括：

- 所有自然音级进（M2、m2）  
- 所有增音程和减音程（包括与协和音程等音的音程，如 A2 和 A1）  
- 所有七度
- 纯四度
