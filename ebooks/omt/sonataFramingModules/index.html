    奏鸣曲式——框架模块（引子与尾声）¶

    奏鸣曲的语法——即支撑这一曲式风格的基本和声与主题"故事"——主要在呈示部、展开部，尤其是再现部中完成。当然，奏鸣曲式乐章通常还要在音乐上讲述其他叙事，而故事越宏大，作曲家就越注意把它整体维系在一起。

    规模较大的奏鸣曲乐章往往有一个或多个框架模块（framing modules）：一个引子、一个尾声，或者两者兼有。它们帮助"框定"全局，并营造一个连贯的音乐叙事——常常是一条弧线：张力逐渐积累到高潮，并在乐章结束时解决到一个相对静止的点上。

    下面列出这些模块的一些常见特征，其中许多与流行/摇滚音乐中的引子和尾声相同。

    引子¶

    引子是第一主题区（P）之前的任何材料。它位于呈示部之外。如果呈示部反复，引子不随之反复。因此，乐谱中作曲家所写的开始反复记号 ||: 可以成为辨认引子结束、呈示部开始的重要视觉线索。由于引子不属于呈示部，它不会在再现部中重现。因此，即使乐谱或演奏中没有反复，一旦辨认出呈示部、展开部和再现部的主题循环，就可以把引子辨认为该循环首次出现之前的音乐。最后，尽管引子材料可能在奏鸣曲后面被引用，但在标准的奏鸣曲乐章中，引子模块只出现一次（这与流行/摇滚音乐的引子不同）。

    引子类型¶

    引子可以非常简短，甚至只是管弦乐队奏出的一个、两个或三个 forte 和弦，作为简单的"提请注意"。贝多芬（Beethoven）"英雄"交响曲开头的两个和弦就是这种简短引子的一个例子。

    较长的引子常常以缓慢的速度与活泼的 P 主题形成对比。这些慢引子有时强调同主音小调式，为大调的 P 主题做准备。它们通常以一个半终止或其他强有力的属到达结束，以引起对随后强调主和弦的 P 主题的期待。作曲家可能会属上停留一段时间，以增强这种期待。贝多芬第四交响曲的引子（下面录音中的 0:00–2:36）就是一个兼具上述所有特点的例子。

    尾声¶

    尾声是跟在再现部主题循环结束之后的一个新模块。换言之，一旦再现部的和声任务已经完成（I:PAC ESC 的到来），并且呈示部的基本主题都已呈现（例如 P TR S C），新的材料往往就落入尾声模块。

    与引子一样，尾声位于再现部之外。因此，如果展开部和再现部反复（这在乐谱中比在现代演奏中更常见），尾声将出现在最后一次反复之后。如果乐谱中没有明确的反复记号，辨认尾声主要依据它出现在被再现的主题材料结束之后。

    有一种常见的例外：呈示部中的小尾声（codetta）常常会在再现部中被扩展，以形成更有力的结尾标点来结束乐章。尾声与小尾声的区别在于：小尾声是呈示部/再现部最后一个终止式的终止后延伸。尾声则做了更多的事情——在和声上，例如造访一个新的调；或在旋律上，例如引入一个新主题，或重访较早的材料，如 P 或展开部。

    可以把小尾声–尾声的关系与流行/摇滚音乐中后副歌（postchorus）–尾声的关系相比较。小尾声或后副歌只是把一个循环的结尾收拢，使其终结性变得清晰。尾声则在旋律或和声上做出引人注目的举动，以完成某种更新颖、更重要的事情。

    贝多芬 C 大调钢琴奏鸣曲 Op. 2, No. 3 第一乐章的结尾（下面录音中从 8:29 开始）就是一个尾声的例子。再现部完成了它的 P TR? S? TR S C 循环。然而，在 C 的一个缩短版本之后，属和弦的一次阻碍解决引向了降 A 大调（降 VI）中的一段游离，其中包含新的旋律材料。在一段和声模进之后，贝多芬在 C 大调中带回了 P 主题的开头，随后以一个夸张而决定性的结尾结束了乐章。新的旋律、新的调区，以及对 P 的相当一部分的使用，都促成了它的尾声性质——并使把它诠释为小尾声的观点难以成立。

    🎧 Spotify：贝多芬 C 大调钢琴奏鸣曲 Op. 2, No. 3 第一乐章

    尽管尾声位于决定性的奏鸣曲结构之外，它常常在乐章中扮演重要的修辞角色。例如，由于降 VI 在小调中是一个近关系调，Op. 2/3 中对降 VI 的强调可以被视为收拢了一个更大的调性故事。作为双 MC 曲式的一部分，贝多芬在呈示部中造访了小调的 V，在再现部中造访了小调的 I。降 VI 上的尾声（与小调的 I 关系密切）可以被诠释为收拢了这个故事——这个故事与常规的奏鸣曲式故事并行，但并不属于后者。在其他情况下，尾声可能只是让作曲家得以延长对一个长乐章中所积累张力的解决，或者完成在展开部中开始却未完成的工作。

    无论哪种情况，重要的是要记住：尽管呈示部和再现部中发生的事情"使奏鸣曲成为奏鸣曲"，但这些框架模块（以及展开部）中发生的事情，往往决定了某一首奏鸣曲的特别之处。一个完整的分析既要处理规范的东西，也要处理偏离的东西；既要处理语法层面，也要处理修辞层面。
