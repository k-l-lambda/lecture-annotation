# 关于开放音乐理论（Open Music Theory）

## 翻转式（或称颠倒式）音乐理论

这本教科书旨在支持理论课堂中*学生对音乐的主动参与*。这意味着，本书在学生的音乐创作（以及拆解）面前应退居次要位置，它并不是课程的中心。

三位原作者在"翻转"或"颠倒"课堂的情境中使用这本教科书，通常遵循一种[探究式模式](http://www.flipcamp.org/engagingstudents/shafferpt3.html)。

因此，本书的大多数页面读起来并不像一本典型的二十世纪教科书。它们介于散文式的讲义与参考资料之间，图示或音频示例也很少。此外，与许多"翻转"课堂资源不同，本书中核心信息以视频形式呈现的资源很少。我们是有意做出这些决定的，为的是让它不只是一本工业时代教科书的多媒体网络版。我们希望创作的是一本能在主动音乐实践的情境中充当快速参考的教科书。

在我们的课堂上，学生的活动居于首位，并且常常*先于*对教科书的阅读。本书所含的信息是从属于这些活动的，因此本书在我们的课堂中只扮演辅助角色。

关于颠倒式音乐课堂的更多信息，参见 *Engaging Students: Essays in Music Pedagogy*（《吸引学生：音乐教学法文集》），[第 1 卷（2013）](http://www.flipcamp.org/engagingstudents/index.html)与[第 2 卷（2014）](http://www.flipcamp.org/engagingstudents2/index.html)。

## 开源

这本"教科书"是一本*开源*教科书。这意味着你可以自由地使用、修改、分发甚至出售其内容，前提是你 1）注明原作者是我们，并且 2）以与我们相同的方式授权你的衍生作品，从而把同样的权利传递给他人（其中也包括我们！）。（参见本书每一页上链接的知识共享许可协议。）事实上，我们非常鼓励他人"改造"这本书：补充它、改写它、增加示例、删去章节、把它与另一本书混编。这不仅意味着可用材料会更加多样，而且如果你通过改造改进了自己的版本，我们也可以利用这些改进来让这份资源变得更好。

如果你想"复刻"（fork）这本教科书，无论是为了在自己的课程中使用，还是作为你自己衍生作品的基础，请访问 [GitHub 项目页面](https://github.com/openmusictheory/openmusictheory.github.io)，登录（或注册），然后点击"fork"。之后你就可以编辑、添加或删除文本、图像和视频（所有文本都采用非常易用的 Markdown 格式），也可以修改主题（HTML 与 CSS）。如果你做了一处你认为值得加入本书的修改，还可以向我们发送"拉取请求"（pull request）。你甚至可以下载单个文件，把它转成讲义在课堂上分发。关于本书背后的开源理念，或关于如何将它用于你自己的目的的更多细节，请阅读 Kris Shaffer 发表在 *Hybrid Pedagogy* 上的文章："[开源学术（Open-Source Scholarship）](http://www.hybridpedagogy.com/Journal/files/Open_Source_Scholarship.html)"与"[推送、拉取、复刻：面向学者的 GitHub（Push, Pull, Fork: GitHub for Academics）](http://www.hybridpedagogy.com/Journal/files/GitHub_for_Academics.html)"。

## 一本批判性的教科书

OMT 不打算成为"一部固定不变的知识巨著，跨越院校边界共享，拥有支配教学决策、裁决学生成败的权威"，而是力求成为一本[批判性的教科书](http://www.hybridpedagogy.com/journal/critical-textbook/)："多作者、可在物理上改造、在法律上可修改"。我们希望这本教科书能够"帮助学生接触既有知识，并赋予他们批判它、拆解它、创造新知识的能力"。

这意味着，有时（而且随着越来越多的人参与写作，这种情况会越来越多）针对同一个问题会给出多种视角。此外，许可协议（以及在尽可能大的程度上，技术本身）允许教师——甚至学生——调整和改写文本。我们并不想跨越院校边界去裁定统一的标准，而是希望本书的在线形式以及配套的话题标签 [#OpenMusicTheory](https://twitter.com/search?f=realtime&q=%23OpenMusicTheory) 能够帮助跨越院校边界建立*社群*，而不是统一性。

虽然在首次"出版"时本书列出了三位作者和一位编辑，但我们希望技术与许可协议能够鼓励其他人为本书贡献新材料。尽管 Kris、Bryn、Brian 和 Robin 是最初的作者和编辑，但我们选择的许可协议和平台实质上把这本教科书的所有权交给了音乐学者与学生的社群。

## Hybrid Pedagogy Publishing

本书由 [Hybrid Pedagogy Publishing](http://www.hybridpedagogy.org/#publishing) 出版，编辑为 [Robin Wharton](http://www.robinwharton.com) 与 [Kris Shaffer](http://kris.shaffermusic.com)。

HPP 所追求的不只是以数字形式复制印刷出版。我们要问的是：*一本数字"书"能做到哪些印刷书做不到的事？* 正如我们在网站上所说：

> 写作与阅读都是社会行为。Hybrid Pedagogy Publishing 致力于鼓励积极的公共讨论，出版那些源于社群（互）动或促进社群（互）动的作品——众包或合作写作的作品、开放获取的作品、鼓励混编和再出版的作品，以及/或者模糊作者与读者界限的作品。

教科书与社群的紧密联系程度几乎无可比拟。因此我们希望，这本教科书以及使用它的社群，能成为我们重新审视在数字互联时代以批判的方式阅读、写作和参与文本意味着什么的一个充满活力的起点。
