# 补集

一个音级集合的*字面补集*（literal complement），是所有不包含在该集合中的音。例如，七音的 C 大调音阶的补集是五音的五声音阶：升 F、升 G、升 A、升 C 和升 D。

任何一个 *n 音集合*（*n-chord*）的补集总是一个 *12−n* 音集合。因此，三音集合的补集是九音集合，四音集合的补集是八音集合，依此类推。

下面你会看到三音集合 [0,1,2]。它的*字面补集*就是所有不属于它的音：[3,4,5,6,7,8,9,T,E]。当我们把这两个音级集合都化为原型时，就称二者互为*抽象补集*（abstract complement）：

![三音集合 [0,1,2] 及其补集](assets/postTonal/complements.png)

在集合类表上，_抽象补集_ 彼此相邻列出，而且它们之间有一种非常有意思的音程关系，比较它们的音程级向量就能看出来。互补的集合类具有相似的音程“分布”。下面你会看到，集合 (012345678) 的每一种音程级都恰好比它的补集 (012) 多 6 个。只有三全音例外：它只多 3 个。
