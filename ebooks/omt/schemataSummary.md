# 加朗特程式——总结

## 开头程式（呈示）

以下这些程式往往出现在主题的开头，常常作为[乐句（句子式）](sentence.md)中呈示乐句的框架。

*注：虽然这些程式在这里以大调呈现，但其中大多数都可以直接转换为小调。

### Meyer

| 阶段： | 1 | 2 | 3 | 4 |
| -: | :-: | :-: | :-: | :-: |
| 旋律： | *do* | *ti* | *fa* | *mi* |
| 低音： | *do* | *re* | *ti* | *do* |
| | | | | |
| 数字低音： | 5/3 | 4/3 | 6/5 | 5/3 |
| 罗马数字： | I | V | V | I |
| 功能： | T | D | D | T |

### Do–Re–Mi

虽然这个程式常见的是三阶段版本，但用于呈示乐句时，这种四阶段版本更为典型。

| 阶段： | 1 | 2 | 3 | 4 |
| -: | :-: | :-: | :-: | :-: |
| 旋律： | *do* | *re* | *re* | *mi* |

| 罗马数字： | I | V | V | I |
| 功能： | T | D | D | T |

（也可以使用原位的属和弦。）

### Romanesca（罗马内斯卡）

| 阶段： | 1 | 2 | 3 | 4 |
| -: | :-: | :-: | :-: | :-: |
| 旋律： | *sol* | *sol* | *do* | *sol* |
| 低音： | *do* | *ti* | *la* | *mi* |
| | | | | |
| 数字低音： | 5/3 | 6/3 | 5/3 | 6/3 |
| 罗马数字： | I | V | VI | I |
| 功能： | T | D | Tx | T |

这个程式的旋律相当灵活，低音和和声才是更具决定性的要素。另请注意，与其他“呈示”程式不同，这个程式在慢乐章中要常见得多。

## 展开程式

### Prinner

| 阶段： | 1 | 2 | 3 | 4 |
| -: | :-: | :-: | :-: | :-: |
| 旋律： | *la* | *sol* | *fa* | *mi* |
| 低音： | *fa* | *mi* | *re* | *do* |
| | | | | |
| 数字低音： | 5/3 | 6/3 | 7–6/3 | 5/3 |
| 罗马数字： | IV | I | VII | I |
| 功能： | S | T | D | T |

或

| 阶段： | 1 | 2 | 3 | 4 | 5 |
| -: | :-: | :-: | :-: | :-: | :-: |
| 旋律： | *la* | *sol* | *fa* | *fa* | *mi* |
| 低音： | *fa* | *mi* | *re* | *sol* | *do* |
| | | | | | |
| 数字低音： | 5/3 | 6/3 | 7–6/3 | 7 | 5/3 |
| 罗马数字： | IV | I | VII | V | I |
| 功能： | S | T | D | D | T |

### 转调型 Prinner

这个程式从主调转到属调。它是转调型乐句（句子式）中常见的展开乐句，也常常作为奏鸣曲/交响曲乐章连接部（transition module）开头那段*全奏*（tutti）的框架。

| 阶段： | 1 | 2 | 3 | 4 |
| -: | :-: | :-: | :-: | :-: |
| 旋律： | *mi* | *re* | *do* | *ti* |
| 低音： | *do* | *ti* | *la* | *sol* |
| | | | | |
| 数字低音： | 5/3 | 6/3 | 7–#6/3 | 5/3 |
| 罗马数字： | I | V | VII/V | V |

或

| 阶段： | 1 | 2 | 3 | 4 | 5 |
| -: | :-: | :-: | :-: | :-: | :-: |
| 旋律： | *mi* | *re* | *do* | *do* | *ti* |
| 低音： | *do* | *ti* | *la* | *re* | *sol* |
| | | | | | |
| 数字低音： | 5/3 | 6/3 | 7–#6/3 | 7/# | 5/3 |
| 罗马数字： | I | V | VII/V | V/V | V |

### Passo Indietro（退一步）

| 阶段： | 1 | 2 |
| -: | :-: | :-: |
| 旋律： | *la* | *sol* |
| 低音： | *fa* | *mi* |
| | | |
| 数字低音： | 5/3 | 6/3 |
| 罗马数字： | IV | I |
| 功能： | S | T |

它本质上就是 Prinner 的前两个阶段。后两个阶段常常被省略（截去），以便给终止式模式腾出位置。

与 Prinner 一样，Passo Indietro 也有一个“转调型版本”（即转调型 Prinner 的前两个阶段）。

| 阶段： | 1 | 2 |
| -: | :-: | :-: |
| 旋律： | *mi* | *re* |
| 低音： | *do* | *ti* |
| | | |
| 数字低音： | 5/3 | 6/3 |
| 罗马数字： | I | V |

## 终止式

### 简单 PAC

| 阶段： | 1 | 2 |
| -: | :-: | :-: |
| 旋律： | *re* | *do* |
| 低音： | *sol* | *do* |
| | | |
| 数字低音： | (7) | 5/3 |
| 罗马数字： | V | I |
| 功能： | D | T |

### 简单 IAC

| 阶段： | 1 | 2 |
| -: | :-: | :-: |
| 旋律： | *fa* | *mi* |
| 低音： | *sol* | *do* |
| | | |
| 数字低音： | 7 | 5/3 |
| 罗马数字： | V | I |
| 功能： | D | T |

### fa–fi–sol HC

这是通往半终止（HC）的一种常见方式，尤其常见于奏鸣曲乐章连接部（TR）的结尾。其决定性要素是低音线条 *fa*–*fi*–*sol*。*re*–*do*–*ti* 的旋律很常见，而且是与这些和声相配的各种可能中最具动力的一种。例子可参见莫扎特（Mozart）K. 545 第一乐章第 10–11 小节，以及 K. 333 第一乐章第 17–18 小节。

| 阶段： | 1 | 2 | 3 |
| -: | :-: | :-: | :-: |
| 旋律： | *re* | *do* | *ti* |
| 低音： | *fa* | *fi* | *sol* |
| | | | |
| 数字低音： | 6/3 | 6/5 | (7) |
| 罗马数字： | II | V/V | V |
| 功能： | S | S | D |

### 复合 PAC

| 阶段： | 1 | 2 | 3 |
| -: | :-: | :-: | :-: |
| 旋律： | *mi* | *re* | *do* |
| 低音： | *sol* | *sol* | *do* |
| | | | |
| 数字低音： | (8)/6/4 | (7) | 5/3 |
| 罗马数字： | Cad. | V | I |
| 功能： | D | D | T |

### 复合 IAC

| 阶段： | 1 | 2 | 3 |
| -: | :-: | :-: | :-: |
| 旋律： | *sol* | *fa* | *mi* |
| 低音： | *sol* | *sol* | *do* |
| | | | |
| 数字低音： | 8/6/4 | 7 | 5/3 |
| 罗马数字： | Cad. | V | I |
| 功能： | D | D | T |

### 复合 HC

| 阶段： | 1 | 2 |
| -: | :-: | :-: |
| 旋律： | *mi* | *re* |
| 低音： | *sol* | *sol* |
| | | |
| 数字低音： | 6/4 | 5/3 |
| 罗马数字： | Cad. | V |
| 功能： | D | D |

（复合 HC 可以由任何 **S** 和弦引入，甚至可以直接接在主和弦延长区域的结尾之后。）

当然，终止式模式远不止这些，但这几种最适合用来搭建即兴演奏或简单的范例写作的框架。关于标准终止式模式的更多细节，参见[古典终止式类型](cadenceTypes.md)。
