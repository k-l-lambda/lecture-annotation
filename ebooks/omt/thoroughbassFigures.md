# 通奏低音导论

*通奏低音*（意大利语 *Basso continuo*，德语 *Generalbaß*，也称*数字低音*）是一段音乐或一部作品的和声速记法。它由一条低音线和称为*数字*的和弦符号组成。之所以称作"通奏"低音或"持续"低音线，是因为它包含了任一时刻发声的最低音，*而不论这个音是由哪件乐器或哪个声部发出的*。它通常对应于某一件乐器或某一个声部，但并非总是如此。

![巴赫《C 大调长笛奏鸣曲》第二乐章，BWV 1033](assets/Bach1033.png)

<!-- lilylet-begin: assets/Bach1033.png -->
```lyl.play
[composer "Johann Sebastian Bach"]
[staves "<fl,bc>"]

\key c \major \time 3/4 \tempo "Allegro" \clef "treble" \stemDown c'16[ g a b] c[ b c d] e[ d c e] \\\\
\key c \major \clef "bass" \stemDown c,8[ g' e g c, g']
_\figures { s4 <6>8 s8 s4 } | %1

\stemDown d'16[ c b a] g[ a b c] d[ e f d] \\\\
\stemDown b,8[ g' d g b, g']
_\figures { <6 5>8 s <6 4 3> s <6 5> s } | %2

\stemDown e'16[ g, a b] c[ b c d] e[ d c e] \\\\
\stemDown c,8[ g' e g c, g']
_\figures { <9>8 s <6> s s4 } | %3

\stemDown d'16[ c b a] \stemUp g4 r \\\\
\stemDown g,8[ g' f g d f]
_\figures { <4>8 <3> <6 4 2> s <6 4> s } | %4
```

*J. S. 巴赫（J.S. Bach），《C 大调长笛奏鸣曲》第二乐章，BWV 1033。上方声部由长笛演奏，下方声部是*通奏低音*线，由一位键盘乐手演奏；他依据谱表下方的数字来确定在这条低音线之上弹奏的和弦。*

通奏低音声部的历史起源在于教堂场合：一首为 6–8 名歌手而写的作品，需要由一两名歌手配合一件键盘乐器来演出。键盘乐手并不去弹奏其余的 4–7 个声部，而是抄下最低音，并用速记的数字标明最低声部之上存在的（单）音程。这样键盘乐手便可以弹奏一两条较重要的声部线条，而用柱式或分解和弦填充其余的织体。（不妨把它想成十七世纪的和弦谱。）一位精通和声与声部进行的优秀键盘乐手，可以只看一条不带数字的低音线（*无数字低音*），一边听旋律一边即兴弹奏其余部分。而经验较少的键盘乐手，则可以通过阅读低音线、记住少量数字和基本的声部进行规则，来应付原本颇为复杂的作品。（关于它的历史，你可以在[这里](bassoContinuo-history.md)读到更详细的说明。）

在我们的学习中，*通奏低音*练习排在类别对位之后。它提供了一个新的、更复杂的环境，让我们练习如何兼顾平滑性、各声部线条的独立性、音调融合（现在要考虑三和弦与七和弦）、多样性以及进行。练习中引入了关于可演奏性的新考量，而核心和声本身就含有不协和音，这也要求我们在这种风格中以新的方式处理和声性不协和。

在本书中，我们将把通奏低音线用于多种目的：

- 对织体浓密或声部进行复杂的作品和段落做和声"缩减"
- 用速记方式表示常见的和声模式
- 作为模式写作练习的和声基础（类似于类别对位中的*定旋律*）

通奏低音是一个简单而又基础的概念。尽早掌握它，后续的学习就会容易得多。

关于数字位置的说明：通奏低音的数字可以写在低音线的上方或下方。两种做法都很常见，但在本书中，我们一般把它们写在低音线*上方*。这样做可以与我们在类别对位中分析音程的习惯相衔接，可以把数字与我们写在低音线下方的其他和声符号区分开，并且在数字和其他符号同时出现时，也更便于在打谱软件中排版。

## 数字

一般而言，通奏低音数字表示和弦中所有音级相对于*低音的上方单音程*。

通奏低音数字中通常出现的最大数字是 7。一般来说，*复音程*（一个八度或更大的音程）都要还原为与之对应的*单音程*。十度变为三度，十三度变为六度，以此类推。

调性音乐中最常见的和弦是[*三和弦*与*七和弦*](triads.md)。下列数字适用于这些和弦：

![三和弦与七和弦的完整数字](assets/harmony/figuresFull.png)

<!-- lilylet-begin: assets/harmony/figuresFull.png -->
```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \key c \major \clef "treble" <e g c>1 \\
\staff "2" \clef "bass" c1
^\figures { <5 3>1 } | %1

\staff "1" <e a c>1 \\
\staff "2" c1
^\figures { <6 3>1 } | %2

\staff "1" <f a c>1 \\
\staff "2" c1 \bar "||"
^\figures { <6 4>1 } | %3

\staff "1" <e g b>1 \\
\staff "2" c1
^\figures { <7 5 3>1 } | %4

\staff "1" <e g a>1 \\
\staff "2" c1
^\figures { <6 5 3>1 } | %5

\staff "1" <e f a>1 \\
\staff "2" c1
^\figures { <6 4 3>1 } | %6

\staff "1" <d f a>1 \\
\staff "2" c1 \bar "|."
^\figures { <6 4 2>1 } | %7
```
<!-- lilylet-end -->

- 5/3：在低音之上使用五度和三度（和弦中会有一个音重复）
- 6/3：在低音之上使用六度和三度（和弦中会有一个音重复）
- 6/4：在低音之上使用六度和四度（和弦中会有一个音重复）
- 7/5/3：在低音之上使用七度、五度和三度
- 6/5/3：在低音之上使用六度、五度和三度
- 6/4/3：在低音之上使用六度、四度和三度
- 6/4/2：在低音之上使用六度、四度和二度

这些数字非常常见，以至于其中大多数都有简写：

![三和弦与七和弦的简写数字](assets/harmony/figuresAbbrev.png)

```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \key c \major \clef "treble" <e g c>1 \\
\staff "2" \clef "bass" c1 | %1

\staff "1" <e a c>1 \\
\staff "2" c1
^\figures { <6>1 } | %2

\staff "1" <f a c>1 \\
\staff "2" c1 \bar "||"
^\figures { <6 4>1 } | %3

\staff "1" <e g b>1 \\
\staff "2" c1
^\figures { <7>1 } | %4

\staff "1" <e g a>1 \\
\staff "2" c1
^\figures { <6 5>1 } | %5

\staff "1" <e f a>1 \\
\staff "2" c1
^\figures { <4 3>1 } | %6

\staff "1" <d f a>1 \\
\staff "2" c1 \bar "|."
^\figures { <4 2>1 } | %7
```
<!-- lilylet-end -->

- 无数字 = 5/3
- 6 = 6/3
- 6/4 从不简写
- 7 = 7/5/3
- 6/5 = 6/5/3
- 4/3 = 6/4/3
- 4/2（或仅写 2）= 6/4/2

其他简写一般遵循两条简单的规则：

- 除非数字中有"6"，否则默认低音之上有五度。
- 除非数字中有"4"或"2"，否则默认低音之上有三度。

## 不熟悉的数字与和弦

上面只列出了七种数字。如果你遇到一个不认识的数字，只需按其音程去做（并运用上述两条简写规则）。同样，如果分析的和弦既不是三和弦也不是七和弦，只需从上到下按降序标出你在低音之上看到/听到的*单*音程即可，例如 7/6/3 或 5/4。久而久之，你会熟悉其他许多和声可能及其相应的数字。

## 五度和弦与六度和弦

所有和弦都可以归为*五度和弦*或*六度和弦*。这一区分对我们学习声部进行很重要。

*五度和弦*包含低音之上的五度，但不包含低音之上的六度。

*六度和弦*包含低音之上的六度。

## 变化音

如果某个音发生了变化（与调号不同），数字也必须相应改变。由于低音本身已经写在低音声部中，低音上的变化音不会体现在数字里。但上方声部中的任何其他变化（例如小调中升高的导音）都必须在数字中体现出来。做法很简单：在相应数字的左侧加上升号、降号或还原号即可。

当然，这里也有一些简写。例如，在数字上画一道线（"斜线"），表示该音升高半音（既可以代替升号，也可以代替还原号）。另外，当变化的是低音之上的三度时，只需写升号、降号或还原号，而省去"3"。

![变化音数字](assets/harmony/figuresChrom.png)

<!-- lilylet-begin: assets/harmony/figuresChrom.png -->
```lyl.play
[staves "{-}"]

\staff "1" \omit Score.TimeSignature \key c \minor \clef "treble" <g' b d>1 \\
\staff "2" \clef "bass" g,1
^\figures { <!>1 } | %1

\staff "1" <d g d'>1 \\
\staff "2" b,1
^\figures { <6>1 } | %2

\staff "1" <g' b d>1 \\
\staff "2" d,1
^\figures { <6+ 4>1 } | %3

\staff "1" <g' b d>1 \\
\staff "2" f,1 \bar "|."
^\figures { <4+ 2>1 } | %4
```
<!-- lilylet-end -->

一般来说，只要有简写可用，就使用简写。简写比相应的完整写法更为标准。

请记住，有些和弦的数字是简写的。例如，在 5/3 和弦中，导音位于低音之上三度是很常见的。在这种情况下，一个本来不需要数字的低音，就需要用一个升号或还原号作为它的通奏低音数字。
