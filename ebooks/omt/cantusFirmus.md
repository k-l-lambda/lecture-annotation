# 写作定旋律

严格声部进行（即类别对位）的练习，从一条单独的、结构良好的音乐线条开始，这条线条叫作**定旋律**（*cantus firmus*，意为“固定的声部”或“固定的旋律”；复数 *cantus firmi*）。写作定旋律让我们有机会处理以下几项基本的音乐特性：

- 平稳
- 旋律线条的独立性与完整性
- 多样性
- 运动（朝向一个目标）

我们在严格声部进行中的第一批练习，就是写作良好、结构完善的定旋律。第一步是演奏并分析范例定旋律，例如下面这条由海因里希·申克（Heinrich Schenker）写的 C 大调定旋律。

[这里](assets/counterpoint/cantusFirmi.pdf)还提供了其他许多范例。演奏这些范例，有助于在内心建立起对结构良好的定旋律的声音与手感的体会；而结构良好的定旋律的许多特征，也同样适用于其他音乐风格。（这些范例定旋律也可以作为我们二声部练习的起点。）

从这些定旋律中可以看到，平稳、旋律完整性、多样性、朝向目标的运动这些一般音乐特性，是如何落实为具体特征的。以下特征是所有结构良好的定旋律所共有的：

- 长度约为 8–16 个音
- 无节奏变化（全部为全音符；没有长音或短音）
- 以 *do* 开始，以 *do* 结束
- 以级进进入最后的主音（通常为 *re*–*do*，有时为 *ti*–*do*）
- 所有相邻两音的进行都是[旋律协和音程](intervals.md)
- 音域（最低音与最高音之间的音程）不超过十度，通常小于八度
- 只有一个高潮（最高点），且在旋律中只出现一次
- 从开头到高潮再到结尾，有清晰的逻辑联系和平稳的轮廓
- 以级进为主，但也有一些跳进（以小跳为主）
- 不重复“动机”或“乐句片段”（licks）
- 任何大跳（四度或更大）之后都以反方向的级进接续
- 不连续超过两次跳进；不在同一方向上连续跳进（富克斯的 F 大调定旋律是个例外，其中连续两次下行跳进勾勒出一个协和三和弦。）
- 导音进行到主音
- 在小调中，导音只出现在倒数第二小节；升高的下中音只在进行到该导音时使用

## 旋律倾向

上面列出的特征相当细致，其中有些是严格类别对位所特有的。不过，综合起来看，它们详细地体现了各种风格中旋律的一些普遍倾向。

[大卫·休伦（David Huron）](https://openlibrary.org/works/OL5851060W/Sweet_Anticipation)指出了西方音乐中旋律的五项普遍属性。它们与上文所列的感知和认知基本原理相关联，但在各种音乐风格中的具体表现略有不同。它们是：

- **音高邻近**（*pitch proximity*）——旋律倾向于级进多于跳进、小跳多于大跳。这体现了平稳与旋律完整性。
- **级进下行倾向**（*step declination*）——旋律倾向于*下行*级进多于上行级进。这可能体现了朝向目标的运动，因为我们往往把向下的进行感知为能量的减少（朝向静止状态的运动）。
- **级进惯性**（*step inertia*）——旋律改变方向的频率低于沿同一方向继续进行的频率。（也就是说，大多数旋律进行与前一个进行方向相同。）这体现了平稳，有时也体现了朝向目标的运动。
- **旋律回归**（*melodic regression*）——处于极端音区的旋律音倾向于回到中间音区。这体现了朝向静止位置的运动（以非极端的音代表“静止”）。这也单纯体现了旋律中音的统计分布：一个音越高，作曲家可选的在它下方的音就越多，在它上方的音就越少。
- **旋律拱形**（*melodic arch*）——旋律倾向于在乐句的前半部分上行，到达高潮，然后在后半部分下行。这体现了目标导向以及“静止—运动—静止”的模式；也是上述各项规则在一个音乐乐句语境中的综合。

在从零开始写作定旋律之前，先试着围绕下面这个骨架构建一条结构良好的定旋律。其中已给出长度、起始音、倒数第二个音、结束音和高潮。请写出一条平稳、协和的旋律线条，体现上面列出的各项特征——既包括严格类别对位定旋律的具体特征，也包括调性旋律的一般特征。点击谱表即可听到旋律。每次改动后都一定要听一听。
