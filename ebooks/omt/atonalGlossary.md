# 无调性音乐术语表

*本术语表远未完成，尚处于编写的最初阶段*

**集合**（collection）——把多个音级当作单一整体来处理时所用的通称。集（set）、集合类、音阶、同时音响、和弦以及音程，都是具体种类的集合。

**音程级**（interval class）——两个*音级*之间的半音数，按它们在钟面上的最短距离计算。例如，C 与 E 构成音程级 4。无论哪个*音高*在上、哪个在下，结果总是如此，因为音程级只关心*音级*。音程级标记为 **ic1**、**ic2**……**ic6**。（不存在小于 **ic1** 或大于 **ic6** 的音程级。）

**音程向量**（interval vector）——一个集合类的音程向量描述该集合类中出现的全部音程级。音程级共有六种（1–6）。音程向量按从 1 到 6 的顺序给出每种音程的数目，并写在尖括号之内。音程向量 **<101102>** 表示该集合含有一个 ic1（半音/大七度）、没有 ic2、一个 ic3（小三度/大六度）、一个 ic4（大三度/小六度）、没有 ic5（纯四度），以及两个 ic6（三全音）。

**有序音高音程**（ordered pitch interval）——从一个音高（而非音级）到下一个音高的半音数。上行音程用正数表示，下行音程用负数表示。例如：B4–G5 的有序音高音程为 8（上行八个半音）。B3–G5 为 20。B4–G4 为 –4。

**有序音级音程**（ordered pitch-class interval）——从一个音级到另一个音级的*上行*半音数。G–B 为四个半音，有序音级音程为 **4**。B–G 为上行八个半音，有序音级音程为 **8**。

有序音级音程也就是有序音高音程的模 12 形式。例如，B4–G4 为 –4 个半音（下行 4 个半音）。mod12(–4) = 8。C3–D4 为 14 个半音。mod12(14) = 2。

**音高**（pitch）——处于特定音区的一个音级，如 C4（中央 C）。

**音级**（pitch class）——半音阶上的十二个音级之一，用一个音名（C、升 D、降 B 等）或一个 0–11 的数字（C = 0，升 C = 1，……B = 11）来概括。在无调性音乐中，拼写很少有意义，除非是为了便于演奏，因此等音的音级被视为同一（C = 升 B = 重降 D = 0）。

**音级集合**（pitch-class set）——音级的一个*无序*集合，通常写在花括号中：{C, E, G}、{D, 降 E, G} 或 {4, 5, 9}。

**音级集合类**（pitch-class set class），或简称**集合类**（set class）——由彼此通过移位或倒影相关联的音级集合所构成的一个类别。例如，12 个大三和弦彼此都通过移位相关联。虽然每个大三和弦都是一个不同的音级集合，但它们都属于同一个集合类（同一类集合）。注意，小三和弦就是上下颠倒的大三和弦（小三度–大三度，而非大三度–小三度）。因此，由于大三和弦与小三和弦可以通过倒影相关联，它们属于同一个集合类。集合类通常按其*原型*来命名（见本术语表中的*原型*）。

**原型**（prime form）——由于集合类最多可有 24 种不同形式（12 种移位乘以 2 种倒影形态），为了便于归类，会从中选取一种形式作为它的名称或参照形式。这一形式就是原型。简而言之，原型就是该集合类在 C（0）上及其上方排列得最紧凑的那种倒影与轮转形式。

**同时音响**（simultaneity）——同时发声的、由不止一个音高（音级）构成的任何集合。这包括二音组/音程、和弦、音簇，以及对位织体中的"萨拉米切片"（salami slices）。

**无序音级音程**（unordered pitch-class interval）——普通的*单*半音音程：两个音高之间的半音数。复音程（大于一个八度）通常被化简为相应的单音程。它们用小写的 **i** 标记：例如，**i4** 是大三度。
