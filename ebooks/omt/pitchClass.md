# 音高（音级）

调性是一个高度带电的体系，其中各个*音级*（scale degrees）都被赋予了一种朝向其他音的磁力或引力。在 C 大调中，还原 B 被主音 C 所吸引，属三和弦的其他成员被主三和弦所吸引，其他音级也各有其功能。在共性写作时期的调性中，*拼写*（spelling）极其重要。降 A 作为降低的第 6 音级会导向 G，而升 G 作为升高的第 5 音级则导向 A。“音级”（scale degree）和“拼写”背后有两个重要的概念，它们将影响我们对后调性音乐的研究。

## 八度等同

“音级”（scale degree）意味着拼写相同、但相隔任意多个八度的[音高](pitches.md)之间存在一种*等同*（equivalence）。C4 与 C3 相同，也与 C9 相同，以此类推。因此，音级这一概念本身就蕴含着*八度等同*（octave equivalence）的观念。

## 等音等同

虽然*八度等同*是我们理解调性音乐的核心，但等音等同（enharmonic equivalence）往往并非如此。在 C 大调中，降 A 和升 G *并不*等同，尽管单独听起来它们是一样的。拼写往往指示着倾向：降 A *下行*到 G，而升 G *上行*到 A。

在后调性音乐中，人们通常默认等音等同——当然也有例外。由于许多作曲家不再感到受调性中心的束缚，我们在调性音乐中看到的那些音与音之间的引力关系就不再重要了。因此，降 A 和升 G 可以被看作同一事物的两种表示。

## 音高

*音高*（pitches）是具有各自频率的离散的音。因此，音高的概念并不蕴含八度等同。C4 是一个音高，它与 C3 不是同一个音高。

## 音级

音级（pitch classes）是在八度等同下、且拼写也相同的*音高*。A4、A3、A2 等都是音级 A 的成员。

## 整数记法

在分析适合默认八度等同和等音等同的后调性音乐时，我们可以用整数来表示音级。所有的 C 以及任何与 C 等音的音（例如升 B）都是音级 0。所有的升 C 以及任何与升 C 等音的音（例如降 D）都是音级 1。依此类推：C = 0，升 C = 1，D = 2，升 D = 3，E = 4，F = 5，升 F = 6，G = 7，升 G = 8，A = 9，降 B = 10（T），B = 11（E）。

## 免责声明！

后调性音乐极其多样。作曲家们各有自己的作曲风格、美学目标和独特的音高观念。这一切都是说，你必须灵活地对待一部作品。例如：由于德彪西（Debussy）的音乐是准调性的，用一种*不*默认等音等同的视角来看待它往往更有益。但有时也并非如此。分析这类音乐时，你必须依靠自己的音乐直觉，并且也应当愿意从多种角度来看待这些作品中的音高，直到找到一种看起来最合适的角度。
