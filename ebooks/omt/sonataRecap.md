# 奏鸣曲式——再现部

*再现部*（recapitulation）是奏鸣曲的目标，它位于*呈示部*和*展开部*之后（呈示部之前的任何内容都是*引子*，再现部之后的任何内容都是*尾声*）。它回应呈示部所提出的预期，并带来*主要结构性终止*。因此，呈示部与再现部之间的关系是奏鸣曲分析的核心焦点。

鉴于这一关系的重要性，对再现部的分析应当始终参照呈示部来进行。

## 主题循环 ##

再现部通常遵循呈示部所确立的同一模块模式：二部式呈示部为 { P TR ’ S / C }，连续式呈示部为 { P TR ⇒ FS / C }（撇号代表 MC，斜线代表 EEC/ESC）。

## 主要结构性终止

再现部（以及整个奏鸣曲乐章）的和声目标是*主要结构性终止（ESC）*。ESC 总是一个 I:PAC，并且通常出现在再现部中与呈示部 EEC 相同的主题位置上。它常常与呈示部中的音乐完全相同，只是从副调移到了主调。

## 重新写作

最简单的呈示部–再现部关系，出现在呈示部中以 I:HC 作为 MC、随后紧接属调上的 S 的奏鸣曲中。在这样的奏鸣曲中，作曲家可以在再现部中把 P–TR 原样重复，然后把 S–C 原样重复，只是向下移低五度。在这样的奏鸣曲中，没有重新写作。再现部中的每一个小节都直接对应于呈示部中的某个小节，或在原音高上，或移位了五度。

然而，在大多数奏鸣曲中，呈示部中的某些音乐会在再现部中被*重新写作*（recomposed），往往是为了"撤销"在通往 V:HC MC 的途中所发生的转调。在这种情况下，我们用*对应小节*（correspondence bars 或 correspondence measures）一词，指称呈示部与再现部中相同（或移位后相同）的段落。*参照小节*（referential bars）明确参照呈示部中的特定小节，但材料以某种并非无关紧要的方式有所改变。*改动*（alterations）则是再现部中与呈示部段落没有明确参照或对应关系的段落。

对应、参照和改动的材料在再现部中往往按以下顺序出现：

- 对应小节（P，或许还有 TR 或 TR ⇒ FS 的开头）  
- 改动或参照小节（主要在 TR 或 TR ⇒ FS 中）  
- 对应小节（S 和 C，有时还有紧接在 MC 之前的材料，移到主调）

### 关键点

再现部中改动让位于与呈示部重新对应的那个点，称为*关键点*（crux）。这一点与 MC 和 ESC 一起，必须在再现部分析的其余大部分工作展开之前确定下来。一般而言，关键点会出现在 S 开始之前，而 S 和 C 主要由*对应小节*构成。

通常在*关键点之后*不会有改动，但如果有的话，在分析中不应忽视它们。

## 诠释学

奏鸣曲分析只是*始于*找出并标记这些模块、调和事件。一旦你成功地分析了奏鸣曲结构，就要进入诠释（研究音乐或文本诠释的学术术语是*诠释学* hermeneutics）。奏鸣曲诠释学始于这样一些诠释性问题：

* 呈示部为再现部（以及其他段落，如展开部和尾声——如果有的话）建立了哪些预期？
* 再现部如何满足这些预期？
* 再现部如何挫败或扰乱这些预期？
* 再现部中预期之内与预期之外的要素可能对听者产生什么效果？
* 所讨论作品的独特要素与其历史语境中的其他作品有何关联？

在撰写、展示或讨论奏鸣曲分析时，不要只是罗列结构。要从这样的问题开始，并且只为解释你对这些问题（以及你在研究作品时所引出的其他问题）的回答而提供结构细节。
