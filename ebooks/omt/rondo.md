# 回旋曲式导论

与奏鸣曲式一样，回旋曲式也有悠久的历史。奏鸣曲源自巴洛克舞曲乐章（主要来自意大利），而回旋曲的历史更为久远，其起源是一种法国器乐体裁——rondeaux（回旋歌），其特征是叠句与形成对比的对句（couplets）交替出现。在器乐奏鸣曲或交响作品中，回旋曲一般出现在快速的终乐章或缓慢的第二乐章中。大概因为回旋曲性格较为轻快，它几乎从不出现在第一乐章。

从概念上说，回旋曲相当简单。这一曲式由与插部交替出现的叠句构成。叠句材料在整个乐章中*保持不变*——有时略加装饰或缩短——并且总是在主调上听到。插部在调性上与叠句形成对比，通常在主题上也形成对比。与叠句不同，回旋曲的插部在整个乐章中不必相同。因此在大的层面上，典型的回旋曲会呈现出 ABAC … A 的曲式；A 代表叠句，B 和 C 表示包含各自独特主题材料的插部。省略号（…）表示叠句和插部的确切数量是可变的，不过五部回旋曲（ABACA）无疑是最常见的。

尽管概念简单，但在实践中，回旋曲也许是在理论上最难描述、在分析上最难把握的曲式。这主要是因为不同的作曲家以不同的方式使用上述简单的回旋曲图式。为了帮助你应对这些偏离，我们将把回旋曲分为两种类型：（1）[五部回旋曲（ABACA）](fivePartRondo.md)，以及（2）[奏鸣回旋曲（ABACABA）](sonataRondo.md)。两种类型的主要区别（我们将在其他回旋曲资源中更详细地讨论）在于：在奏鸣回旋曲中，第一个叠句和第一个插部构成一个完整的奏鸣曲呈示部，并在第三个叠句和插部中得到再现（插部移到主调）。学会辨认回旋曲式中最常见的[主题功能](thematicFunctionInRondo.md)类型，是重要的第一步。
