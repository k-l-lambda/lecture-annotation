# 正常序

正常序（normal order，有时也称为正常形式 normal form）与三和弦“原位”的概念有很多共同之处。原位的作用之一，是为三和弦和七和弦的音级提供一种标准的排列方式，使我们能够方便地对它们进行分类和比较。正常序的作用相同，但方式更为一般化，从而可以适用于包含各种不同音和音程的和弦。

正常序是书写某一给定音级集合的最紧凑方式。通常，你可以借助键盘或钟面凭直觉确定正常序，但学会一套总能给出正确答案的步骤是有好处的。

1. 把它写成一个音级集合（去掉重复的音级），按上行顺序排列，并限定在一个八度之内。可能的写法有很多种。
2. 在末尾重复写一次第一个音级。
3. 找出相邻音级之间最大的有序音级音程。
4. 从最大音程右侧的那个音级开始，重新书写这个集合，并把答案写在方括号中。

例如，给定 {升 G4, A2, 升 D3, A4}：

1. *把它写成一个音级集合（去掉重复的音级），按上行顺序排列，并限定在一个八度之内。* {8,9,3}
2. *在末尾重复写一次第一个音级。* {8,9,3,8}
3. *找出相邻音级之间最大的有序音级音程。* 在这个例子中，最大的音程位于“9”和“3”之间。
4. *从最大音程右侧的那个音级开始，重新书写这个集合，并把答案写在方括号中。* [3,8,9]

偶尔你会在第 3 步中遇到并列的情况。这时，把每一种并列所对应的排列都写出来，并计算从第一个音级到倒数第二个音级的音程。音程最小的那种排列就是正常序。
