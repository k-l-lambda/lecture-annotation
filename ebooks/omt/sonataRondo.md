# 奏鸣回旋曲式

奏鸣回旋曲（ABACABA）具有与五部回旋曲相同的叠句–插部交替，但奏鸣曲式的某些方面渗入了这种交替之中。

| **呈示部** | | | **展开部** | **再现部** | | |
|---|---|---|---|---|---|---|
| 叠句 1 | 插部 1 | 叠句 2 | 插部 2 | 叠句 3 | 插部 3 | 叠句 4 |

1. 叠句 1 和插部 1 构成一个奏鸣曲呈示部，它在叠句 3 和插部 3 中得到再现。与奏鸣曲式中的情况一样，再现部包含一个"调性调整"，使其结束在主调上。也就是说，插部 1 和插部 3 在主题上相同，但插部 3 出现在主调上。
2. 由于它类似于奏鸣曲式，第一和第三插部总是构成为"第二主题"复合体。
3. 插部 2（上面简写图式中的 C）可以是一个展开部——可能包含准备区、CAZ 和回归连接——也可以是一个较简单的内部主题。
